# Guitar Overview

เอกสารภาพรวมของเส้นทางกีต้าร์ในสวนนี้: เขียนให้ใคร ควรเรียนอะไรก่อนหลัง และอะไรที่ยังไม่ได้ทำ

เลข `#` ในตารางตรงกับ `order` ของบทใน `site/src/content/lessons/guitar/` และคอลัมน์ความยากตรงกับ `level` (1 ง่าย ถึง 5 ยาก)

## 1. เขียนให้ใคร

ทุกระดับ บทแรก (รู้จักกีต้าร์) มีตารางบอกว่าคนเริ่มใหม่ คนเล่นตามหู และคนเล่นเก่งควรเริ่มตรงไหน ตัวเนื้อหาเขียนสองชั้น ชั้นแรกอธิบายจากพื้นฐาน ชั้นที่สองเป็นกล่อง "ลงลึก" และ "ท้าทาย" สำหรับคนที่รู้แล้ว แบบทดสอบท้ายบทใช้เป็นตัวชี้ว่าบทไหนข้ามได้

กลุ่มที่เขียนถึงเป็นพิเศษคือคนที่เล่นกีต้าร์มาหลายปีแต่เล่นตามหู ไม่เคยเรียนอย่างเป็นระบบ จึงมีของดีสามอย่าง (หู ความรู้สึกต่อกรูฟ เพลงในมือ) และช่องว่างที่พบบ่อย (ไม่รู้ชื่อโน้ตบนคอ เปลี่ยนคอร์ดไม่ทัน ติดกรอบ pentatonic กรอบเดียว ไม่รู้คีย์ของเพลง)

เส้นทางนี้เน้นการลงมือซ้อม แต่ละบทจบด้วย "งานสัปดาห์นี้" ที่มีตัวเลขหรือเกณฑ์ให้ตรวจ ส่วนเหตุผลเชิงทฤษฎีอยู่ในเส้นทางทฤษฎีดนตรี (`music-theory`) ซึ่งเรียนแยกหรือควบคู่กันได้ บทกีต้าร์อ้างถึงบททฤษฎีด้วยชื่อบท

## 3. สิ่งที่ตรวจแล้ว และสิ่งที่ยังไม่ได้ตรวจ

| เรื่อง | สถานะ |
|---|---|
| ตัวเลขในบท "รู้จักกีต้าร์" (ระยะเฟร็ต 25.5 และ 24.75 นิ้ว ที่ 650 มม. แรงตึงสาย .010 ประมาณ 73 N) เฟร็ตที่ได้ harmonic (12, 7, 19, 5, 24, 9, 4) ตรงกับ node ของสายจริง harmonic เฟร็ต 5 สาย 6 เท่ากับเฟร็ต 7 สาย 5 และ glossary ไม่ซ้ำคำ ทุกลิงก์บทมีจริง | รันตรวจแล้ว |
| รูปคอร์ดทุกกล่องในบท (ชื่อตรงกับโน้ตจริง มี root เป็นเบส) | รันตรวจแล้วด้วย `subjects/music-theory/code/verify.mts` |
| ชื่อโน้ตบนสาย 6 และ 5, กฎอ็อกเทฟ (+2 หรือ +3 เฟร็ต), ข้อยกเว้น G–B | รันตรวจแล้ว |
| กรอบ A minor pentatonic กรอบ 1 (เฟร็ต 5 ถึง 8) และตำแหน่งสเกลทั้งหมดในแล็บ | รันตรวจแล้ว (กรอบ 1) ส่วนอื่นสร้างจากอัลกอริทึมเดียวกัน |
| รูป CAGED ห้ารูปของ C G A E D F B♭ และคอร์ดบาร์ F กับ B | รันตรวจแล้ว |
| คำแนะนำด้านการสอน (ท่านั่ง แรงกด กติกาซ้อม ลำดับฝึก) | ไม่ได้ตรวจ เขียนจากแนวปฏิบัติทั่วไปของการสอนกีต้าร์ ปรับตามตัวเองได้ |
| ชื่อและหน้าที่ของแต่ละส่วนในหน้า anatomy (วัสดุที่พบบ่อย ความกว้าง nut 43 กับ 52 มม. classical มักไม่มี truss rod เสียงสะท้อนอากาศในกล่องราว 100 Hz ลำดับ 5 ขั้นของเสียง) และภาพเคลื่อนไหวเสียงเดินทาง | ไม่ได้ตรวจกับแหล่งอ้างอิง เขียนจากความรู้ทั่วไปของงานช่างกีต้าร์และอะคูสติก ตัวเลขเป็นค่าประมาณ ภาพวาดเป็นแผนภาพ ไม่ใช่สัดส่วนจริง |
| ประวัติและชื่อรุ่น/ยี่ห้อ/ปีในบท "รู้จักกีต้าร์" | ไม่ได้ตรวจกับแหล่งอ้างอิง เขียนจากความรู้ทั่วไป ปีเป็นค่าโดยประมาณ (เขียนกำกับไว้ในหน้า) |
| เสียงในแล็บ (สตรัม เมโทรนอม) | ยังไม่ได้ทดสอบในเบราว์เซอร์จริงในรอบที่สร้าง ต้องเปิดฟังเอง |
| เพลงอ้างอิงช่วงเสียงในแล็บทฤษฎี (anchor songs) | เขียนจากความจำ แต่ละคนควรเลือกเพลงของตัวเอง |

## 4. ยังไม่ได้ทำ (backlog)

- **ฟิงเกอร์สไตล์**: รูปแบบนิ้วขวา (p i m a) ลายเบสสลับ
- **คอร์ดขยายและ voicing**: คอร์ด 9 11 13, shell voicing, ไตรแอดบนชุดสาย (ต้องต่อกับทฤษฎีบทที่ 6 และ 8)
- **จังหวะขั้นสูง**: สิบหกส่วน (ฟังก์) สวิง และ 6/8
- **อ่านโน้ตและแทบ**: ตอนนี้บทใช้แทบสั้นๆ เท่านั้น
- **เสียงและอุปกรณ์**: แอมป์ เอฟเฟกต์ ปิ๊กอัพ การเซ็ตอัพ
- **เล่นกับวง**: การฟังคนอื่น เบสไลน์ง่ายๆ
- แล็บที่ยังไม่มี: เมโทรนอมแยกต่างหาก ตัวจับเวลาซ้อม ตัวสร้างลูปบลูส์สิบสองห้อง
