  options={[
    'In a file on the computer of the consumer',
    'In the internal topic __consumer_offsets, in the partition we get by hashing the group name and taking the remainder by 50',
    'In ZooKeeper',
    'In the memory of the producer'

  answer={1}

  q="We want a group to read a topic again from the start after fixing the code, but a consumer of the group is still running. What should we do?"
  options={[
    'Run the reset offsets command with execute straight away, while the consumer is still reading',
    'Stop the consumers of the group first (so the group is empty) and then run the reset, because Kafka refuses to rewind while the group has members',
    'Delete the topic and create it again',
    'Add partitions'
  ]}
  answer={1}
  why="If we rewound while a consumer was running, that consumer would commit over the value we just set, so Kafka answers that assignments can only be reset if the group is inactive, as the exercise saw (ran). Always look at the result with a dry run first."
/>

</Step>
