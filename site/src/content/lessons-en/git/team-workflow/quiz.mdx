## Check yourself

<Question
  client:visible
  lang="en"
  q="Which of these is really the Git part of a pull request?"
  options={['The green button that merges the work', 'A branch pushed to a remote and the way to compare it with Main and combine it', 'The comment box under the code']}
  answer={1}
  why="The button and the comment box belong to the hosting site, and Git does not know pull requests. What Git does is keep the branch, let us push it, compare, and combine, all of which the exercise runs without any website."
/>

</Step>

<Step kind="question">

<Question
  client:visible
  lang="en"
  q="We want to see only the work of Topic, when Main has moved on since Topic split off. What should we compare with?"
  options={['The tip of Main directly against the tip of Topic', 'Three dots joining the two names, which compares from the point where they split', 'The option Stat alone']}
  answer={1}
  why="Comparing the two tips directly shows the new work of Main as something missing from Topic. Three dots start from the common ancestor, so we see only the work of Topic. The exercise prints both: the first has a file of Main mixed in, and the second leaves only the file of Topic."
/>

</Step>

<Step kind="question">

<Question
  client:visible
  lang="en"
  q="A team wants the history of Main to be a short straight line, with each pull request being a single commit. Which way of combining should it choose?"
  options={['A merge commit', 'Squash', 'It cannot be done']}
  answer={1}
  why="A squash folds the work of a branch into one commit with one parent, so the history of Main stays short and straight. The exercise confirms there is one commit and the original commits of the topic are not in the history. The cost is that Git does not count that branch as merged. A merge commit keeps every commit and has a joining point."
/>

</Step>

  answer={1}

The exercise checks that a fetch from Upstream brings the new commit, and that it merges into our Main as a fast-forward. Sending work back to the main repository happens through a pull request from the fork."
