## Check yourself

<Question
  client:visible
  lang="en"
  q="We run a mixed reset back one commit. Where does the change of the commit we stepped back from end up?"
  options={['Left in the index, ready to commit at once', 'Left in the working tree, not yet staged', 'Gone entirely']}
  answer={1}
  why="Mixed moves the branch and sets the index to match the new commit, but does not touch the files in the folder, so the change stays in the folder as unstaged. The exercise confirms that afterwards the staged list is empty, the changed file is listed, and the content is still that of the commit we stepped back from. A soft reset leaves it in the index and a hard reset removes it."

  q="We did a hard reset and lost uncommitted edits. What about the commit we stepped back from?"
  options={['It was deleted too', 'It is still in the repository, and Git noted the old position in Orig Head', 'It moved into the stash']}
  answer={1}
