## Check yourself

<Question
  client:visible
  lang="en"
  q="The history has commits from oldest to newest C1, C2, C3, C4, C5, and we are on C5. Which commit does the name Head followed by a tilde and the number three point at?"
  options={['C2, because it goes back three steps along the parents', 'C3, because it counts three up from C1', 'C1, because it goes back to the very start']}
  answer={0}
  why="A tilde followed by N goes back N steps along the parents. From C5 one step is C4, two is C3 and three is C2. The exercise checks that going back three steps from the tip of a history of five commits gives the second commit."
/>

</Step>

<Step kind="question">

<Question
  client:visible
  lang="en"
  q="We want to see only the commits that touched the file readme. What do we put at the end of the Log command?"
  options={['Just the file name, directly after', 'Two dashes and then the file name, to separate the commit name from the file name', 'The option Stat, which filters by itself']}
  answer={1}
  why="Two dashes tell Git that what follows is a path and not the name of a commit, which avoids confusion when a file has the same name as a branch. The exercise gets only the commits that changed readme. The option Stat shows how many lines were changed, it is not a filter."
/>

</Step>

  q="A commit made by merging two lines has two parents. If we were standing on Main and brought in Feature, what is the second parent?"
  options={['Main before the merge', 'Feature, the branch we brought in', 'The first commit of the project']}
  answer={1}
  why="The first parent is the line we stood on at the time of the merge, which is Main, and the second is the line we brought in. The exercise asserts that the first parent is the commit on Main before the merge and the second is the tip of Feature."
