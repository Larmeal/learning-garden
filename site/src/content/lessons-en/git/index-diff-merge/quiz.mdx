  q="The time of a file was changed but not the content, and Git Status is empty. Does that mean Git checked the content?"
  options={['No, Git trusts the time of the file', 'Yes, because the stat differed from what was remembered, Git opened the file and compared the id, found it the same, so the status is empty', 'Yes, but it checks against the remote']}

<Question

  q="Four diff algorithms give different results. Does that mean some of them are wrong?"
  options={['Wrong, because there is only one correct result', 'No, every one applied to the old file gives the new file, they only choose differently which lines count as the same', 'All wrong except the default one']}
  answer={1}
  why="A diff is a set of additions and removals that turns the old file into the new one, and many sets can do it.
