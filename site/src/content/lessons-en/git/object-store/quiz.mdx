  q="In which kind of object is a file name such as notes txt stored?"
  options={['Blob', 'Tree', 'Commit']}
  answer={1}
  why="A blob holds only the content of the file. The file name and the mode are in the entries of a tree, which acts as the folder. <Question
  client:visible
  lang="en"
  q="Why does changing a commit in the middle of the history change the ids of every commit after it?"
  options={['Because Git picks a random new id every time it saves', 'Because every commit has a parent line inside its text, which is used to compute the id, so when a parent changes the id changes, one after another', 'Because Git deletes the old history and writes it again']}
  answer={1}
  why="The id of a commit is the SHA-1 of the whole text, including the parent line. The exercise computes the id of a commit itself from the text and gets what Git gives, and checks that the second commit has a parent line pointing at the first. When a parent differs, the text differs, so the id differs all along the line."
/>

</Step>
