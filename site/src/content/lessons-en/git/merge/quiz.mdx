## Check yourself

<Question
  client:visible
  lang="en"
  q="Main has no new commits since Topic split off, and Topic has three more commits. We merge Topic into Main in the ordinary way. What is the result?"
  options={['Git makes a new merge commit with two parents', 'Git moves Main to the tip of Topic, with no new commit', 'Git reports a conflict']}
  answer={1}
  why="Main is already an ancestor of Topic, so there is no work on the Main side to combine. Git fast-forwards, which only moves Main ahead.   options={['The side we brought in', 'The side we were standing on when we ran the merge', 'The common ancestor']}
  answer={1}
  why="The upper part is the version of the branch we are on, and the lower part is the branch we brought in. The exercise confirms from a real file that the line Tuna that we made on Main is in the upper part, and Egg, from the other branch, is in the lower. The common ancestor's version is not in the file in the normal style. We only see it when we ask for the Diff3 style."
