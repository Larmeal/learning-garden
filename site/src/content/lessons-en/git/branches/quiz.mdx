<Question

  q="While we are on an ordinary branch, what does the HEAD file in the repository hold?"
  options={['The full name of the latest commit', 'The name of the branch we are on, for example Refs Heads Main', 'The list of all the files of the project']}

  q="We go to a detached HEAD on an old commit, work on and make new commits, and then switch back to Main without doing anything else. What happens to those new commits?"
