## Check yourself

<Question
  client:visible
  lang="en"
  q="A browser opens an HTTPS site and the handshake succeeds, but the certificate the server sent names another site, and the client has name checking turned off. Which is true?"
  options={['The connection is still encrypted, but we do not know whose server we are talking to', 'The handshake always fails, because TLS forces the names to match', 'It is safe, because a CA signed that certificate']}
  answer={0}
  why="With name checking off, the handshake succeeds and the data is encrypted, but anyone who got a certificate from the same CA for a site of their own can stand in for another site. The exercise leaves checking on and gets Hostname mismatch, which is why the name check matters as much as the encryption."

<Question
  client:visible
  lang="en"
  q="In the handshake lab, which message is the biggest, and why?"
  options={['Message 1, because the client sends its whole list of ciphers', 'Message 2, because the server sends its certificate with it', 'Message 3, because it carries the user data']}
  answer={1}
  why="The exercise measured the client at 1,524 bytes, then the server at 1,818 bytes, then the client at 80 bytes. Message 2 is the biggest because the certificate travels with it. These numbers depend on the certificate and the OpenSSL version where it ran. Message 3 is tiny because it only says the client has finished checking. User data is sent after that."
/>

</Step>

  q="A server's certificate expired yesterday and everything else is correct. What does a client with all the checks on do?"
  options={['It carries on, because the CA can still be trusted', 'It refuses, with the message certificate has expired', 'It connects, but without encrypting the data']}
  answer={1}
  why="The age of the certificate is one of the three things the client checks (the CA, the name, the dates). The exercise makes a certificate that started 100 days ago and lasts 30, and the client refuses it with certificate has expired. Short lifetimes mean a certificate whose key leaked stops working on its own before long."
