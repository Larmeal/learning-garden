## Check yourself

<Question
  client:visible
  lang="en"
  q="A designer wants to store each user's four digit PIN as a SHA-256 because it cannot be reversed. Which answer matches what the exercise shows?"
  options={['Safe, because SHA-256 really cannot be reversed', 'Not safe, because there are only 10,000 possibilities, so trying each one and comparing the hash takes seconds', 'Safe if we use SHA-512 instead']}
  answer={1}
  why="Not reversible does not mean not guessable. The exercise tries 0000 to 9999 and compares hashes, and finds the PIN on the 7,352nd try. SHA-512 would still leave only 10,000 possibilities. The problem is that the space to guess is too small, not the size of the hash."
/>

</Step>

<Step kind="question">

<Question
  client:visible
  lang="en"
  q="We write a config file for two of our own services to read, and want to know whether anyone changed it on the way. Both services keep the same secret key. Which tool fits best?"
  options={['HMAC, because both sides already share a key', 'A signature, because only a public key is needed', 'A plain hash, because it is the fastest']}
  answer={0}
  why="The two sides trust each other and share a key, so HMAC fits: it is fast and simple. A signature would work too, but it fits better when the checker is someone we have not given a secret key to. A plain hash can simply be recomputed by whoever changed the file."
/>

</Step>

<Step kind="question">

<Question
  client:visible
  lang="en"
  q="We encrypt a message with AES-GCM and someone flips one bit of the ciphertext on the way. What happens when we decrypt?"
  options={['We get a message that is wrong at that position', 'Decryption fails with InvalidTag and no message comes out', 'It decrypts as usual, because encryption does not check for changes']}
  answer={1}
  why="AES-GCM is authenticated encryption, so it checks the tag before returning any text. The exercise flips one bit and gets InvalidTag. That is better than getting garbled text, because the program never uses changed data without knowing."
/>

</Step>

<Step kind="question">

<Question
  client:visible
  lang="en"
  q="A team releases a new version of a program and wants every user to be able to check that the file came from the team, without giving anyone a secret key. What should it use?"
  options={['HMAC, giving the key to every user', 'A signature, handing out only the public key', 'AES-GCM, giving the key to every user']}
  answer={1}
  why="If the HMAC or AES-GCM key is handed to everyone, anyone can use it to make a fake as well. A signature separates the signing key from the checking key. The public key can be given to everybody, and anyone can check, but nobody can sign for the team."
/>

</Step>
