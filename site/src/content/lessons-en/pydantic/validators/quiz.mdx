## Check yourself

<Question
  lang="en"
  client:visible
  q="username: str has an after field_validator. The user passes username=123. What happens?"
  options={['The validator is called with 123 and isalnum() fails', 'The validator is not called, because Pydantic checks the type first and gets string_type', 'Pydantic converts 123 to \'123\' and then calls the validator']}
  answer={1}
  why="An after validator runs only once the type check has passed. str does not accept numbers (lesson 3), so you get string_type and the validator is never called. So an after validator can trust the type of its value."
