## Check yourself

<Question
  lang="en"
  client:visible
  q="A field x: Union[int, str] (smart mode, the default) receives '5'. What do you get?"
  options={['5 as an int, because int is leftmost', '\'5\' as a str, because \'5\' already is a str and matches that member with no conversion', 'An error, because it is ambiguous']}
  answer={1}
  why="Smart mode lets the member whose type matches exactly win before any lax conversion. The order inside the brackets does not matter when a member matches. With union_mode='left_to_right' you would get 5."
/>

</Step>

<Question

  q="Cat and Dog share name. You pass {'name': 'x'} into Union[Cat, Dog]. Which model do you get, and what if you swap to Union[Dog, Cat]?"
  options={['Cat and Dog respectively, a tie goes to the left', 'Cat both times', 'An error, because it is ambiguous']}
  answer={0}

  q="What is the advantage of a discriminated union when the data is wrong, compared with a plain union of the same models?"
  options={['It reports the errors of every member, which is more detailed', 'It picks a member from the tag and reports only that member\'s errors, so the message is short and on point', 'It has no errors at all']}
  answer={1}
  why="In the exercise, {'kind': 'card'} with number missing gives one error, card.number. A plain union gives three, including two that are irrelevant because the data was never a QrPay."

<Question

  client:visible
  q="You pass {'kind': 'cash'} into a discriminated union that knows only 'card' and 'qr'. Which error do you get?"
  options={['literal_error', 'union_tag_invalid', 'union_tag_not_found']}
  answer={1}
  why="The tag is there but matches no member, so you get union_tag_invalid. union_tag_not_found is for when the discriminating field is missing from the data altogether (for example passing only {'ref': 'r1'})."
/>

</Step>

<Question

  q="When do you need Discriminator(function) with Tag instead of Field(discriminator='kind')?"
  options={['When you want it to be faster', 'When the data has no simple discriminating field and you must decide from the shape or type of the value yourself', 'When the union has more than two members']}
  answer={1}
  why="A callable discriminator receives the value and returns a tag name itself, for example by checking whether it is an int or a str. If it returns None you get union_tag_not_found. The exercise example uses int and str, which have no field to look at."
