  q="json.dumps(e.errors()) fails with TypeError when the error came from raise ValueError in a validator. Why, and how do you fix it?"
  options={['ctx[\'error\'] holds an exception object that json.dumps does not know. Fix it with e.json() or include_context=False', 'loc is a tuple, which JSON cannot hold', 'input is a string that is too long']}
  answer={0}
  why="When a validator raises ValueError, ctx['error'] keeps the original exception. json.dumps cannot convert an exception. e.json() converts it to text ({'error': 'too big'}). A tuple converts to a JSON array, so it is not the cause."
