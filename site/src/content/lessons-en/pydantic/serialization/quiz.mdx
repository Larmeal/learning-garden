  q="Rect has a computed_field named area. You pass Rect(w=1, h=1, area=99). What is area?"
  options={['99', '1, because the passed value is ignored and area is computed from w * h', 'ValidationError']}
  answer={1}
  why="A computed_field affects output only and is not an input field. The value area=99 is ignored like any unknown key (extra defaults to ignore), and area comes out as 1."
