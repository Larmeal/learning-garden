  q="A router in the middle sees a packet with an HTTP message inside. Does it open and read that message?"
  options={[
    'Always, to know where to send it',
    'No, it uses only the IP header to choose the outgoing cable',
    'Only the first line of the HTTP',

  ]}
  answer={1}
  why="A router works at the network layer. It reads the destination from the IP header and picks the outgoing cable, and it does not need to know whether TCP or HTTP is inside.   q="A packet leaves the client with TTL 64 and the server sees TTL 63. If there were three routers in between, what TTL would the server see?"
  options={['64', '63', '61', '60']}
  answer={2}
  why="Each router lowers the TTL by one when it forwards, so three routers leave 64 - 3 = 61. The exercise has one router, so it leaves 63 (ran)."

</Step>
