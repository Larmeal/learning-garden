    'The content of the HTTP request',

    'The server name asked for in the ClientHello (SNI) and the destination IP address',
    'The password the user typed'
  ]}
  answer={2}
  why="The ClientHello is sent before there is a key, so the server name is readable, and a router has to read the IP header to forward the packet. The certificate in TLS 1.3 is encrypted after the ServerHello. The content and the password are encrypted data (ran)."
