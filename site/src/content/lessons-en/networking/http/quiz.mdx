  options={[
    'The server sent them in short form',

    'The client sent less because its window shrank',
    'TCP compressed them'
  ]}
  answer={1}
  why="HPACK is the header compression of HTTP/2. It uses a table that both sides build in the same way, so a repeated header is sent as a pointer. In the exercise the server's HEADERS also shrank to 2 bytes in the later answers (ran, RFC 9113 section 4.3)."
