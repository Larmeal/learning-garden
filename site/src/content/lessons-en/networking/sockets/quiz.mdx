  answer={1}

  q="A program opens short connections to the same API tens of thousands of times a minute, and starts to get the error Cannot assign requested address on the client. What is the most likely cause?"
  options={[
    'The server is down',
    'The ephemeral ports for that destination have run out, because many connections are lingering in TIME-WAIT',
    'DNS is wrong',
    'The server\'s window is 0'
  ]}
  answer={1}
  why="EADDRNOTAVAIL happens in connect, before a SYN is sent, when the kernel cannot find a free source port for that destination. The exercise saw it when the port range was cut to three numbers. In real systems it is usually many sockets in TIME-WAIT, and it is fixed with a connection pool or keep-alive, so as not to open a new connection every time (ran and author)."
/>

</Step>
