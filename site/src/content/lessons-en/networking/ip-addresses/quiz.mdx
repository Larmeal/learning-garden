<Question

  lang="en"
  q="How many computers can use addresses of the network 10.0.1.0/24?"
  options={['256', '255', '254', '253']}
  answer={2}
  why="/24 leaves 8 host bits, so there are 2 to the power 8 = 256 addresses. But the first (10.0.1.0) is the name of the network and the last (10.0.1.255) is the broadcast, so 254 can be used for computers (ran)."
/>

</Step>

<Step kind="question">

<Question
  client:visible
  lang="en"
  q="What do you get when you AND the address 10.0.1.2 with the mask 255.255.255.0?"
  options={['10.0.1.2', '10.0.1.0', '10.0.0.0', '255.0.1.0']}
  answer={1}
  why="AND works bit by bit. In the first three octets the mask is all ones, so the values stay (10, 0, 1). In the last octet the mask is all zeros, so it becomes 0. The result 10.0.1.0 is the address of the network (ran)."
/>

</Step>

<Step kind="question">

<Question
  client:visible
  lang="en"
  q="Two routers are joined by one cable. What prefix should that cable get so that no addresses are wasted?"
  options={['/24', '/28', '/30', '/16']}
  answer={2}
  why="/30 leaves 2 host bits, so 4 addresses, of which 2 can be used for computers, exactly the two ends of the cable. The other two are the network name and the broadcast. A /24 would waste 252 addresses (ran)."
/>

</Step>

<Step kind="question">

<Question
  client:visible
  lang="en"
  q="A router has separate routes to 10.0.4.0/24, 10.0.5.0/24, 10.0.6.0/24 and 10.0.7.0/24, all leaving through the same cable. What single route can replace them?"
  options={['10.0.4.0/21', '10.0.4.0/22', '10.0.0.0/22', 'They cannot be joined']}
  answer={1}
  why="Four neighbouring /24 networks that start at 4, which is divisible by 4, join into exactly one /22: 10.0.4.0/22 covers 10.0.4.0 to 10.0.7.255. Starting at 10.0.1.0 would not work, because a /22 has to start at a number divisible by 4 (book: TCPIP section 2.4.2, page 48)."
/>

</Step>
