<Question

  q="According to the measurements, how do you calculate the number of stages of an operation that has a shuffle?"
  options={['The total number of operations', 'The number of Exchange nodes in the plan, plus 1', 'The number of partitions divided by 8']}
  answer={1}
  why="Every Exchange is a stage boundary, so groupBy (1 Exchange) gets 2 stages and a sort-merge join (2 Exchanges) gets 3 stages. The exception is orderBy, which has an extra stage that samples the data."
