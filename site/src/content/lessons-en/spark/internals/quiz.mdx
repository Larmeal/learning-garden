  options={['360 MiB (600 x 0.6)', '180 MiB ((600 - 300) x 0.6)', '300 MiB']}
  answer={1}
  why="Subtract the reserved 300 MiB first, then multiply by 0.6. The measured value was 188,743,680 bytes = 180 MiB, which matches the formula. Half of it (90 MiB) is the storage region by the default of storageFraction."

<Question
  client:visible
  lang="en"
  q="You cache data with MEMORY_ONLY until storage uses more than half of the unified memory, and then run a sort that needs a lot of memory. What happens?"
  options={['The sort fails because storage does not give memory back', 'Execution takes it back by evicting the storage blocks that borrowed beyond the line. The measured result was that the cache kept 2 of 4 partitions', 'Storage evicts execution instead']}
  answer={1}
  why="Storage can borrow free space from execution, but execution can take it back (by evicting storage blocks over the line). Storage cannot take memory back from execution, so there is no guarantee that a MEMORY_ONLY cache stays complete."
/>

</Step>
