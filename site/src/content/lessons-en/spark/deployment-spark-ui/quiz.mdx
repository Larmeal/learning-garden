## Check yourself

<Question
  client:visible
  lang="en"
  q="The application has ended, and you want to open the Spark UI afterwards. What must you have done before?"
  options={['Nothing. The Spark UI is kept on the driver forever', 'Turned on spark.eventLog.enabled when it ran (it is off by default), and then used the History Server to read the event log', 'You must run on YARN only']}
  answer={1}
  why="The Spark UI lives on the driver only while the application runs. If the event log is on, Spark writes every event (for example the 14 task start/end events in the lab) to a file, and the History Server replays those events as the same UI pages."

</Step>

  options={['Some executors are missing', 'There is probably skew, which means some tasks got much more data than the others', 'shuffle.partitions is always too small']}

<Question

  lang="en"
  q="Which of these cannot be done in Spark Connect?"
  options={['df.collect() and df.explain()', 'df.rdd and spark.sparkContext, because they need a JVM that the client does not have', 'df.filter and df.groupBy']}
  answer={1}
  why="The Connect client builds a logical plan and sends it over gRPC to the server. There is no JVM on the client side, so it cannot reach SparkContext and RDD (PySparkAttributeError and PySparkNotImplementedError in the experiment). Transformations, collect and explain work."
/>
