## A DataFrame is a table with a schema

A DataFrame has rows and columns. Every column has a name and a data type (the schema), but the data is spread over many partitions on many executors. You write as if you were using one table, and Spark divides the work.

Each basic operation has an equivalent in SQL.

| DataFrame API | SQL |
|---|---|
| `select("a")` | `SELECT a` |
| `filter(cond)` or `where(cond)` | `WHERE cond` |
| `groupBy("c").agg(...)` | `GROUP BY c` |
| `join(other, on)` | `JOIN other ON ...` |
| `orderBy("c")` | `ORDER BY c` |

## DataFrame API and SQL

Both go into the same optimizer (Catalyst, lesson 6), so you can choose the one that is easier to read for the job, and you can mix them.

```python
df.createOrReplaceTempView("t")
spark.sql("SELECT country, SUM(sales) FROM t GROUP BY country")
```

## NULL

NULL is the most common cause of unexpected results in this lesson. There are three rules.

- Aggregate functions such as `sum` skip NULL.
- `count(col)` counts only the rows where `col` is not NULL, and `count(*)` counts every row.
- Comparing NULL with any value gives NULL, not true or false. So `filter` drops that row.

<Callout type="warn" title="Check NULL with isNull()">
`F.col("sales") == None` does not work, because the comparison always gives NULL and the filter drops every row. Use `F.col("sales").isNull()` or `isNotNull()` instead.
</Callout>

</Step>

## Try it on your machine

<Callout type="try" title="Run the same data as in the picture">

```python
from pyspark.sql import functions as F
from spark_session import get_spark

spark = get_spark("sales")
rows = [("th", "bkk", 120), ("th", "cnx", 80), ("jp", "tyo", 200), ("jp", "osa", None), ("sg", "sin", 90)]
df = spark.createDataFrame(rows, "country string, city string, sales int")

df.groupBy("country").agg(
    F.sum("sales").alias("total"),
    F.count("sales").alias("n_sales"),
    F.count("*").alias("n_rows"),
).orderBy("country").show()
```

The result on Spark 4.2.0:

```
+-------+-----+-------+------+
|country|total|n_sales|n_rows|
+-------+-----+-------+------+
|     jp|  200|      1|     2|
|     sg|   90|      1|     1|
|     th|  200|      2|     2|
+-------+-----+-------+------+
```

The jp group has two rows but `n_sales` is 1, because the osa row is NULL.
