<Question
  client:visible
  lang="en"
  q="Why does envelope encryption make rotating the master key much cheaper than using one key for every row?"
  options={['Because the master key is smaller', 'Because we only unwrap and wrap the data keys again (3 keys, 180 bytes in the exercise) and do not touch millions of rows', 'Because the master key never has to change']}
  answer={1}
  why="The data is encrypted with a data key, not with the master key. Rotating the top level therefore rewrites only the wrapped data keys. The exercise works out 180 bytes, against 92,500,000 bytes if every row had to be encrypted again."
/>

</Step>

<Question

  q="A request asks for all of one table to be deleted, and copies exist on a backup tape that cannot be edited. How does crypto-shredding help?"
  options={['It deletes the data from the tape directly', 'It deletes the data key of that table. Every copy was encrypted with the same key, so when the key is gone every copy is unreadable', 'It moves the tape somewhere else']}
  answer={1}
