<Question

  lang="en"
  q="A container has a CPU limit of 100m and the program loops using all the CPU it can. What happens to it, and which cgroup file decides this?"
  options={[
    'It is killed at once, decided by memory.max',
    'It is squeezed to about 10% of one CPU (throttled), decided by cpu.max',
    'It is moved to a node with more CPU',
    'Nothing, because a CPU limit is only a hint'
  ]}
  answer={1}
  why="A CPU limit becomes cpu.max (10 ms in every 100), which pauses the program for part of each period. This is called throttling. It differs from memory, where going over the limit gets the process killed."
/>

</Step>
