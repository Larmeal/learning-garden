<Question

  lang="en"
  q="A CRD whose schema says that the field replicas must be an integer no higher than 5 has been created. We create an object of that kind with replicas set to 9. What happens?"
  options={[
    'The object is stored, and then an operator changes it to 5',
    'The API server refuses it at once with a message that it is above the maximum, and nothing is stored',
    'The object is stored but marked as in error',
    'Kubernetes adjusts the value to 5 by itself'
  ]}
  answer={1}
  why="The schema in a CRD is enforced by the API server when it receives the object, so it refuses before storing, with no need to wait for an operator."

<Question
  client:visible
  lang="en"
  q="The operator we wrote works as a loop that repeats. Which statement gives the three steps of the loop correctly?"
  options={[
    'Wait for a command from the user, do it, then stop',
    'Look at what exists, compare it with what the object wants, fix the difference, and then go round again',
    'Create everything again from scratch in every round',
    'Delete everything and wait for somebody to create it again'
  ]}
  answer={1}
  why="An operator is a controller with the same shape as the loop in the first lesson: look, compare, act. In the exercise it created when something was missing, repaired when it was deleted, and updated when the spec changed."
/>

</Step>

<Step kind="question">

<Question
  client:visible
  lang="en"
  q="We delete a Greeter object while the operator is not running. Why does the Deployment it made go away as well?"
  options={[
    'The operator is hiding somewhere in the cluster and keeps working',
    'The Deployment has an ownerReference pointing at the Greeter, so the garbage collector of Kubernetes removes what is left without its owner',
    'The API server deletes every object whose name starts the same way',
    'The kubelet deletes it when the Pod ends'
  ]}
  answer={1}
  why="An ownerReference is the relationship between an owner and what it made. When the owner is deleted the garbage collector removes what remains. Operators use it so that they do not have to write cleanup code themselves."
/>

</Step>
