## Check yourself

<Question
  client:visible
  lang="en"
  q="What did the exercise get when it built an image twice from the same file without cache?"
  options={['The same image ID, because the file is the same', 'Different image IDs, although the file is identical byte for byte', 'The second build failed']}
  answer={1}
  why="An image carries the time it was created and the times of the files copied into it, so building again gives a new ID. This is why we build once and promote by moving a tag, instead of building per environment."
