## Check yourself

<Question
  client:visible
  lang="en"
  q="You run terraform apply again without changing the code. What happened in the exercise, and what is this property called?"
  options={['It made a second set of files, called replication', 'Nothing changed (0 added, 0 changed, 0 destroyed), called idempotent', 'It failed because the files exist, called a conflict']}

  q="After changing app_version from 1.0.0 to 1.1.0 the plan says 1 to add, 1 to destroy. Why not 1 to change?"
  options={['Because Terraform does not know how to edit a file', 'Because the local provider treats a change of the content as requiring the resource to be replaced (must be replaced), which is how this kind of resource behaves.   answer={1}
  why="The plan line says plainly local_file.config must be replaced, because the content of this kind of resource cannot be changed in place. motd.txt is not touched at all, which shows that Terraform changes only what differs."

</Step>
