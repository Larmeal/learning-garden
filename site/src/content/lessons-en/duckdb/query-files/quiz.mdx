  q="A CSV uses `;` between fields and writes the price as `7,5`. We call `read_csv` with no options. What type will the price column have?"
  options={[
    'DOUBLE, because DuckDB knows a comma is a decimal point',
    'INTEGER, because DuckDB drops what follows the comma',
    'VARCHAR, because `7,5` is not a decimal number that DuckDB reads by default',
    'It cannot be read at all and the query stops at once'
  ]}
  answer={2}
  why="The sniffer finds the delimiter and the quote by itself, but `7,5` is not yet a number for it, so it keeps text. If we force DOUBLE we get an error that names line 2 and the value `7,5`. The fix is `decimal_separator = ','` (ran)."
