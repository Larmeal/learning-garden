<Question

  lang="en"
  q="When does DuckDB still fail with an Out of Memory Error even though spilling is on?"
  options={[
    'Never, because spilling works for every operator',
    'When an operator must hold one block of state that cannot be split to disk, such as a list gathering 50 million numbers in one cell under a 100 MB limit',
    'When a Parquet file is bigger than memory_limit',
    'When more than 8 threads are used'
  ]}
  answer={1}
  why="In the exercise a 365 MB Parquet file was read and summed under a 64 MB limit, because the scan passes vectors on. A single list of 50 million values failed, and the error message gave the fixes (fewer threads, switch off preserve_insertion_order, raise memory_limit) (ran)."
/>

</Step>
