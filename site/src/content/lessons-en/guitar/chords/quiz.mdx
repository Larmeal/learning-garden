  q="What is the one-by-one test used for?"
  options={['Training faster chord changes', 'Finding strings that sound muffled or buzz in a chord you have already fingered, so that you fix only that string', 'Tuning the strings']}
  answer={1}
  why="One strum does not let you hear which string is wrong. Plucking one string at a time separates the problem, and you can fix the finger pad or the pressing position exactly."
