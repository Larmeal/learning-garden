## A scale is a map, not a rule

A scale is a set of notes chosen from the twelve notes. A song uses notes mainly from one set, and the scale tells you what is in that set. When you know the scale of a song, you know which notes "fit". Notes outside the set sound tense or strange. You can use them for color, but you must know that you are using them.

The problem for players who use only one box is that the box is just one of 5 to 7 shapes that cover the same set of notes. The same notes repeat in many places on the neck. If you know all five boxes, you can play the same scale along the whole neck and you do not have to return to the same box every time.

"What a scale is and how it is built from a formula" is in the music theory path, in the lesson "[The major scale and keys](/en/music-theory/major-scale-keys/)". This lesson uses only the result.

</Step>

## Minor pentatonic: the first scale to know well

Pentatonic means five notes. Minor pentatonic uses the degrees **1 ♭3 4 5 ♭7** of the key. For example, A minor pentatonic is A C D E G. It has no note that clashes with the main chords in rock and blues, so it is the safest scale to start improvising with.

Box 1 of A minor pentatonic is at frets 5 to 8. The index finger is at fret 5 (A on string 6).

```text
e|-5-8-
B|-5-8-
G|-5-7-
D|-5-7-
A|-5-7-
E|-5-8-
```

Box 1 of A minor pentatonic: the numbers are frets. Every string has two notes. The note A is at fret 5 of string 6, fret 7 of string 4 and fret 5 of string 1 (the dark circles in the map below).

See all 5 boxes and change the key in the map below. Press "Next" to move from one box to the next. Notice that neighboring boxes always overlap by two frets.

## One set of notes, two names

A minor pentatonic is A C D E G, and C major pentatonic is C D E G A. They are **the same set of notes**. The only difference is which note is the resting point (root).

- In a song whose main chord is Am, feel A as home. Call it A minor pentatonic.
- In a song whose main chord is C, feel C as home. Call it C major pentatonic.

In practice, **the shape is the same, but the root moves.** Box 1 of A minor pentatonic is at frets 5 to 8, and C is at fret 8 on string 6, which is 3 frets higher than A. An easy rule is: **to play the major pentatonic of key X, use the minor pentatonic box whose root is three frets below X** (C major pentatonic uses the A minor pentatonic box at fret 5).

Test it with the map above. Choose A + Minor pentatonic and look at the notes, then change to C + Major pentatonic. The lit notes on the neck are the same. Only the root note differs.

</Step>

## Seven-note scales: major and natural minor

The major scale has a pattern of distances between notes (whole step = W, half step = H) of **W W H W W W H**. For example, C major = C D E F G A B.

On the guitar, it is usually divided into seven positions. Each position has three notes per string (3 notes per string) and covers about five to seven frets. There are seven positions because there are seven notes to start from. Use the map above, choose Major, and look at each position.

Natural minor (the Aeolian mode) is the major scale starting from its 6th note. A natural minor is the same set of notes as C major, starting on A. This is why both pentatonic scales have all their notes inside the same seven-note scale (A minor pentatonic is a subset of A natural minor).

<Callout type="note" title="Blues scale">
The blues scale is minor pentatonic with one added note, ♭5 (the middle note, the "blue note"). For example, A blues = A C D E♭ E G. Use it as a passing note and do not stay on it long. The tense sound you hear in the blues comes from this note. See it in the map above by choosing Blues.
</Callout>

## Practice in a way that is more than running up and down

Running a scale up and down does not make you able to improvise. It only teaches your fingers the positions. The next step is to train your fingers to play "phrases".

| Level | Exercise | Result |
|---|---|---|
| 1 | Run up and down one box at 60 bpm, saying the note names aloud | Finger positions and note names are linked |
| 2 | Run in groups of three notes (1-2-3, 2-3-4, 3-4-5 ...) | The fingers play short phrases instead of a straight line |
| 3 | Skip notes (1-3, 2-4, 3-5 ...) | You can play wider jumps without getting lost |
| 4 | Slide back and forth along one string, then join the boxes | You see how the boxes connect |
| 5 | Circle around the root: start on any note and return to end on the root | Trains the ear to know which note is "home" |

**How to remember the five boxes:** do not memorise them as five shapes. Remember which note of the scale you start on, on string 6. The first box starts on the root, the next box starts on the next note of the scale, and so on. Then follow the shape your hand already knows.

**This week's task:** choose one key (A or E is recommended because the root is close to the nut). Learn box 1 and box 2 of minor pentatonic and run them up and down cleanly at 80 bpm. Then play them in the style of level 2 (groups of three notes).
