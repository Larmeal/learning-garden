## Check yourself

<Question
  lang="en"
  client:visible
  q="A test fails with assert 0.30000000000000004 == 0.3. What is the best fix?"
  options={['Change it to assert round(x, 20) == 0.3', 'Use assert x == pytest.approx(0.3)', 'Change == to != and hope it passes']}
  answer={1}
  why="As floats, 0.1 + 0.2 is not exactly 0.3 (the exercise confirms that 0.1 + 0.2 != 0.3 is true). pytest.approx compares with a tolerance, a relative 1e-6 by default. Rounding to 20 places does not help because that is finer than a float can hold."

  answer={0}
  why="pytest.raises is a context manager and match is a regular expression that is searched for in the message, so the message qty must be positive, got 0 passes even though match is only a part of it. The third option also passes when nothing is raised at all, so it checks nothing."
