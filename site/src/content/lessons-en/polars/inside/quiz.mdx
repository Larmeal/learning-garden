<Question
  client:visible
  lang="en"
  q="How much memory do the values of an Int64 column of one million rows use without a null, and about how much more does a single null add?"
  options={['8,000,000 bytes, plus about 125,000 bytes for the validity bitmap', '1,000,000 bytes, plus 8 bytes', '8,000,000 bytes, and nothing more, because the null uses a slot that is already there']}
  answer={0}
  why="Eight bytes per row is 8,000,000 bytes, and the bitmap uses one bit per row, a million bits being about 125,000 bytes. The exercise got 8,125,009 bytes with one null."

<Question
  client:visible
  lang="en"
  q="You call to_numpy and forbid copying, on a column without a null. What do you get?"
  options={['An array that points directly at Polars memory, and cannot be written to', 'A new array that was always copied', 'An error always, because NumPy does not accept Polars data']}
  answer={0}
  why="A column without a null is a block of numbers side by side that NumPy can point into, so it is a read-only view. A column with a null needs a bitmap that NumPy has no place to keep, so it must be copied, and if you forbid copying you get an error."
/>

</Step>
