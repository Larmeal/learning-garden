  client:visible
  lang="en"
  q="In our pipeline 250 rows have the text 'many' as the quantity. After a non-strict cast to integers and a filter for quantity above 0, where do those rows go?"
  options={["They stay, because 'many' becomes zero", 'They are filtered out, because the cast fails and gives null, and null above 0 gives null, which does not pass the condition', 'An error already at the cast']}

  why="With strict set to false, a value that cannot be converted becomes null, and by the rule of null from [lesson 3](/en/polars/types-and-nulls/) a comparison gives null, which a filter does not keep. These rows disappear together with the negative ones."
