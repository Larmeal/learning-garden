## Check yourself

<Question
  client:visible
  lang="en"
  q="Customer Cat has 2 rows, and one of them has no quantity (null). What do pl.len() and the count of the quantity column give in this group?"
  options={['2 and 2, because they count rows the same way', '2 and 1, because len counts every row and count counts only values that exist', '1 and 1, because both skip the incomplete row']}
  answer={1}
  why="len counts all rows of the group and the count of a column skips null. In the sample table Cat gives 2 and 1. The difference between the two is an easy way to see how many values a column is missing in each group."

</Step>

<Question
  client:visible
  lang="en"
  q="You compute a running sum per customer (cum_sum with a window) on a table sorted by order. What is Ann's first running sum, when the row before it in the table belongs to someone else?"
  options={['The sum of all earlier rows plus Ann’s, because the table runs on', 'Just that row’s own amount, because the accumulation starts again in every group', 'null, because the first row of a group has nothing to accumulate yet']}
  answer={1}
  why="over makes every function inside see only the rows of its own group. Ann's running sum starts at 3.0 and goes to 10.5 and 34.5. It is the shift(1) value in the first row of a group that is null."
/>

</Step>

  q="You call group_by with no order option and write the result to a file. Why might the files of two days differ?"
  options={['Polars randomises values, so the numbers differ', 'The order of the groups is not guaranteed, even if the values in each group are the same', 'group_by sorts by run time, so it changes every day']}
