  q="A DataFrame has 7 columns. You put the same product expression in select and in with_columns. How many columns does each result have?"
  options={['select gives 1 column and with_columns gives 8 columns', 'Both give 8 columns', 'select gives 8 columns and with_columns gives 1 column']}
  answer={0}
  why="select keeps only what you ask for, so only the product column remains. with_columns keeps the old columns and adds the new one, so 7 plus 1 is 8."

<Question

  q="In one select you take the order_id column (8 rows) together with the sum of qty (a single value). What is the result?"
  options={['An error, because the lengths differ', '8 rows, with the sum repeated on every row', '1 row, because the shortest value decides the length']}
  answer={1}
  why="A single value is broadcast to the length of the other columns. Any other mismatch (for example 3 against 8) gives a ShapeError."

<Question
  client:visible
  lang="en"
  q="In a when chain you test qty >= 4 first and test for a missing value after it. With 'small' as the final fallback, which label does the row whose qty is missing get?"
  options={["'unknown', because Polars already knows the value is missing", "'big', because a missing value counts as the largest", "'small', because the comparison gives null, which is not true, so the row falls through to the last branch"]}
  answer={2}
  why="when checks from top to bottom and decides at the first branch that is true. A comparison that gives null is not true, so it flows on to the next branch. To get an 'unknown' label you must catch the missing value first. The exercise checked that row 8 gets 'small' when the order is wrong."
/>

</Step>
