<Question

  q="Today's file arrives as an empty table. Which kind of expectation should guard against this?"
  options={['ExpectColumnValuesToNotBeNull', 'ExpectTableRowCountToBeBetween', 'ExpectColumnValuesToBeUnique']}
  answer={1}
  why="An empty table has no rows to check. A column map expectation (one that checks each row of a column) passes by default. You need a table-level expectation on row count to catch it."
