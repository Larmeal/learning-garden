## A suite with two levels

The main lesson proposed three policies. This page writes them for real (`29_pipeline_policies.py` part 1, GX 1.24.1). The suite for the orders table has two rules.

```python
gxe.ExpectColumnValuesToNotBeNull(column="order_id")          # default severity: critical
gxe.ExpectColumnValuesToBeBetween(column="amount", min_value=0, max_value=1000,
                                  mostly=0.99, severity="warning")
```

And three kinds of data:

| Data | What it is | Highest level of the failed ones |
|---|---|---|
| good | `order_id=[1, 2]`, `amount=[10, 20]` | none (`None`) |
| warning only | `amount` has 5000 (over 1000) | `warning` |
| critical | `order_id` has a null | `critical` |

The highest level is read from `suite_result.get_max_severity_failure()` for each validation in `run_results` (it returns `None` if everything passed, and it has `.value` as the string `"warning"` or `"critical"`).

## Three policies

```python
def apply(policy, name, result, state):
    sev = severity_of(result)
    if result.success:
        state["published"].append(name)
    elif policy == "stop":
        state["stopped"].append(name)
    elif policy == "quarantine":
        state["quarantine"].append(name)
    elif policy == "warn then continue":
        if sev == "critical":
            state["stopped"].append(name)
        else:
            state["published"].append(name)
            state["alerts"].append(name)
```

Choose a policy to see where each kind of data ends up. All results come from real runs.

## How to choose

- If you do not set `severity`, every rule is `critical`. So the policy "warn and continue" stops in every failing case, which has the same result as "stop".
- `mostly=0.99` lets the `amount` rule be wrong in at most 1% of rows. The test data has 2 rows, so the one row over the limit is 50%, and the rule fails.
- The "quarantine" policy in the script is just a list in the program. In real work you need a real holding area and a way for users to see the previous run. This part was not tested.

<Callout type="warn" title="Choose the policy at the start">
The policy depends on which is more expensive: the damage from bad data, or the damage from late data. This is a decision for the team and the data owner. GX gives you the tools to read the result and separate the levels. It does not choose for you.
</Callout>
