## What is the same, and what differs

Both ways check the data and store the result in the results store in the same way. Script `25_checkpoint_shapes.py`, parts 5 and 6, measures the differences you can see (GX 1.24.1).

| Topic | `vd.run(...)` | `checkpoint.run(...)` |
|---|---|---|
| Results stored in the store | 1 entry per run | 1 entry per validation (2 validations give 2) |
| `meta["checkpoint_id"]` of the result | `None` | has a value |
| What it returns | `ExpectationSuiteValidationResult` | `CheckpointResult` (has `run_results`) |
| Where `result_format` is set | A parameter of `run()` | A field of `Checkpoint(...)` (not a parameter of `run()`) |
| Parameters of `run()` (from `inspect.signature`) | `checkpoint_id`, `batch_parameters`, `expectation_parameters`, `result_format`, `run_id` | `batch_parameters`, `expectation_parameters`, `run_id` |
| actions | none | can be set in `Checkpoint(actions=[...])` ([lesson 9](/en/great-expectations/actions-data-docs/#what-an-action-is)) |

</Step>

## result_format moved

Switch between the tabs to see where the `result_format` that you used to pass to `vd.run` goes when you use a checkpoint.

The numbers 0 and 9 are the number of keys in the `result` of the first item of the suite `vd_age`, with `BOOLEAN_ONLY` and `COMPLETE` respectively. This matches what [lesson 4](/en/great-expectations/reading-results/#result_format-more-detail-costs-more) saw: BOOLEAN_ONLY makes `result` empty.

## How to choose

| Situation | Choose |
|---|---|
| Trying rules, writing an experiment script, checking once | `vd.run(...)` or `batch.validate(...)` ([lesson 6](/en/great-expectations/datasources-batches/#which-file-does-get_batch-pick)) |
| A regular check in a pipeline | `Checkpoint`, because it joins several checks into one run (the same `run_id`) and can attach actions |
| You want to know which checkpoint a result came from | `Checkpoint` (it has `checkpoint_id` in meta) |
| You want a different `result_format` for each check | Create separate checkpoints for the level you need |
