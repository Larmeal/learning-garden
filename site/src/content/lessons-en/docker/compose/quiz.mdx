  options={[
    'info, because it is the default in the file',

    'warn, because a variable from the shell beats the .env file',
    'A mix of all three'
  ]}
  answer={2}
  why="The order the exercise saw is that a value set in the shell wins. If the shell does not set it, the value from the .env file is used, and if neither exists, the default after the dash is used (ran). docker compose config helps us see the file after substitution before we really run it."

</Step>
