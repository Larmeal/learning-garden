  q="We run a web server container with a publish option bound to the address 127.0.0.1. Who can call that port?"
  options={[
    'Every computer on the network, because publishing means opening it to everyone',
    'Only programs on our own computer, calling through 127.0.0.1, because the port is bound to that address only',
    'Nobody, because 127.0.0.1 is closed',
    'Only other containers on the same network'
  ]}
  answer={1}
  why="The 127.0.0.1 in -p binds the door to the loopback address that only our own computer can reach. The exercise saw that a call from our computer reached, and docker port showed the port bound to 127.0.0.1 as specified (ran). Other containers do not need this door, because they reach each other directly on one network. Writing only the port number without an address was not tried."
/>

</Step>
