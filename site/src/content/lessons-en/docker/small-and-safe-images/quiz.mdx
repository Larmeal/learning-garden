  options={[
    'The container still runs as the ordinary user, because the image forces it',
    'The container runs as root, because an option given at run time always overrides the image',
    'Docker refuses to run it',
    'The container runs as both users at once'
  ]}
  answer={1}
  why="An image author cannot prevent a container from running as root, because whoever runs it can change the user. The exercise gave User 0 to an image with USER app and got uid 0 (ran), as the book says. The best an author can do is set a non-root user as the default (book: Docker in Action section 8.6.2, page 169)."
