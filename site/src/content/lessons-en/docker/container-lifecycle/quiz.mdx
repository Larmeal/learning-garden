    'Both stop at once with exit code 0',

    'The first stops at once and the second has to wait out the grace period',
    'Both wait out the grace period and are killed by SIGKILL'
  ]}
  answer={1}
  why="A sleep that is PID 1 has no handler for SIGTERM, so that signal does not kill it. The exercise measured 5.3 seconds with -t 5 and exit code 137. The Init option puts a small init program in as PID 1 and it passes SIGTERM on to the sleep, which dies of that signal within 0.3 seconds, and the code is 143, which is 128 plus 15 (ran)."
