## ตารางข้อมูลและสิบสามกฎ

สคริปต์ `19_catalog_nulls.py` สร้างตาราง 5 แถว มีคอลัมน์ `id`, `age` (มี Null หนึ่งแถวและค่า 400), `plan` (มี Null หนึ่งแถว), `start`, `end`, `a`, `b` แล้วรัน Expectation สิบสามข้อใน Suite เดียว (GX 1.24.1) และจัดผลตามตระกูล ส่วนตระกูล Query (`UnexpectedRowsExpectation`) ไม่ได้รันในสคริปต์นี้ ให้ดูตัวอย่างที่รันแล้วใน[บทที่ 12](/great-expectations/custom-expectations/other-kinds/#query-เมื่อกฎเป็น-sql-อยู่แล้ว)

| ตระกูล | ตัวอย่างที่รัน | Key ใน `result` |
|---|---|---|
| Column Map | `ExpectColumnValuesToBeBetween`, `...ToBeInSet`, `...ToBeUnique`, `...ToMatchRegex` | `element_count`, `missing_count`, `unexpected_count`, `unexpected_percent`, `partial_unexpected_list` และ Key ที่เกี่ยวกับ Index |
| Column Map ที่ทดสอบ Null เอง | `ExpectColumnValuesToNotBeNull`, `...ToBeNull` | เหมือนข้างบน แต่ไม่มี `missing_count` |
| Column Aggregate | `ExpectColumnMaxToBeBetween`, `...MeanToBeBetween` | `observed_value` อย่างเดียว |
| Column Aggregate (ชุดค่า) | `ExpectColumnDistinctValuesToBeInSet` | `observed_value`, `unexpected_count`, `partial_unexpected_list` |
| column pair map | `ExpectColumnPairValuesAToBeGreaterThanB` | Key ชุดเดียวกับ Column Map |
| Multicolumn Map | `ExpectCompoundColumnsToBeUnique` | Key ชุดเดียวกับ Column Map |
| Table (Batch) | `ExpectTableRowCountToEqual`, `...ColumnCountToEqual` | `observed_value` อย่างเดียว |

ตระกูล Map ทั้งสามแบบ (Column, Pair, Multicolumn) ให้ผลหน้าตาเดียวกัน เพราะทั้งหมดนับแถวที่ผิด ส่วน Aggregate กับ Table ได้ค่าเดียว

ผลมีสองจุดที่ไม่ตรงกับที่คาด

- `ExpectColumnDistinctValuesToBeInSet` ได้ `observed_value` เป็น `None` ทั้งที่ผ่านและไม่ผ่าน ดังนั้นถ้าต้องการรู้ว่ามีค่าอะไรบ้าง ต้องดู `partial_unexpected_list` ของมัน (ทดลองเพิ่มด้วยข้อมูลที่มีและไม่มี Null ได้ผลเหมือนกัน)
- `ExpectColumnMeanToBeBetween(0, 120)` กับ `age = [10, None, 30, 40, 400]` ได้ค่าเฉลี่ย 120.0 พอดีและผ่าน เพราะช่วงรวมปลายทั้งสองข้าง และค่าเฉลี่ยคิดจาก 4 ค่าที่ไม่ใช่ Null (500 ÷ 4)
