## แปดบรรทัดที่ประกอบ Workflow

```python
context = gx.get_context()
source = context.data_sources.add_pandas("people_src")
asset = source.add_dataframe_asset("people")
bdef = asset.add_batch_definition_whole_dataframe("whole")
suite = context.suites.add(gx.ExpectationSuite(name="people_suite"))
suite.add_expectation(gxe.ExpectColumnValuesToNotBeNull(column="id"))
vd = gx.ValidationDefinition(name="people_vd", data=bdef, suite=suite)
result = vd.run(batch_parameters={"dataframe": df})
```

สคริปต์ `17_object_chain.py` พิมพ์สถานะหลังทุกบรรทัด (GX 1.24.1) โดยคอลัมน์ `engine_rounds` นับจำนวนครั้งที่ Execution Engine ถูกเรียกคำนวณ Metric

| หลังบรรทัด | id | อยู่ใน Context | engine_rounds |
|---|---|---|---|
| `get_context()` | (Ephemeral Context) | ว่าง | 0 |
| `add_pandas` | มี | Data Source 1 ตัว | 0 |
| `add_dataframe_asset` | มี | Asset 1 ตัวใต้ Source | 0 |
| `add_batch_definition_whole_dataframe` | มี | Batch Definition | 0 |
| `ExpectationSuite(name=...)` | `None` | ยังไม่มี Suite | 0 |
| `context.suites.add(...)` | มี | มี `people_suite` | 0 |
| `suite.add_expectation(...)` | Expectation ได้ id | | 0 |
| `ValidationDefinition(...)` | `None` | ยังไม่มี Validation Definition | 0 |
| `vd.run(...)` | มี (ถูก Add ตอนรัน) | มี `people_vd` | 5 |

ตารางนี้บอกเราสองเรื่อง เรื่องแรกคือ Object ที่สร้างด้วย `add_*` จะได้ id ทันที ส่วน `ExpectationSuite(...)` กับ `ValidationDefinition(...)` ที่สร้างด้วยคอนสตรัคเตอร์ยังไม่มี id และยังไม่อยู่ใน Context จนกว่าจะ Add หรือรัน อีกเรื่องคือการคำนวณกับข้อมูลเกิดที่บรรทัดสุดท้ายบรรทัดเดียว

## run() Add ให้ได้เฉพาะตัวมันเอง

`ValidationDefinition.run` เพิ่มตัวเองเข้า Context ได้เมื่อ Suite และ Batch Definition ที่มันอ้างอยู่ใน Context แล้ว ถ้า Suite ยังไม่ถูก Add เราจะได้ `ValidationDefinitionRelatedResourcesFreshnessError` พร้อมข้อความให้เรียก `context.suites.add(...)` ก่อน (ข้อความเต็มอยู่ในหน้า "[Error แรกที่ต้องเจอ](/great-expectations/core-concepts/first-errors/)")

Validation Definition อ้าง Suite ด้วยชื่อกับ id (หน้า "[อ้างอิงกันด้วยชื่อและ id](/great-expectations/core-concepts/references/)") ดังนั้น Suite ที่ไม่ได้ Add จึงไม่มี id ให้อ้าง ข้อนี้เป็นการอนุมานจากข้อความ Error กับรูป Json นะ ไม่ได้อ่านโค้ดส่วนนี้ทีละบรรทัด

<Callout type="note" title="ตรวจเองได้">
รัน `uv run python 17_object_chain.py` ในโฟลเดอร์ `subjects/great-expectations/code/` แล้วเทียบกับตารางได้เลย id เป็น UUID สุ่มจึงต่างกันทุกครั้ง แต่ `None` กับมีค่าต้องตรงกัน
</Callout>
