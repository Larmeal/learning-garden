## ตารางข้อความ Error

ทุกแถวมาจาก `17_object_chain.py` (GX 1.24.1, Pandas, Context แบบ Ephemeral) ข้อความถูกตัดให้สั้นลง

| ทำอะไร | Exception | ข้อความ | ทางแก้ |
|---|---|---|---|
| ส่ง Suite ที่ยังไม่ Add เข้า `ValidationDefinition` แล้วรัน | `ValidationDefinitionRelatedResourcesFreshnessError` | `ExpectationSuite 'never_added' must be added to the DataContext before it can be updated. Please call context.suites.add(...)` | `suite = context.suites.add(suite)` ก่อนสร้าง Validation Definition |
| เรียก `run()` โดยไม่ส่ง `batch_parameters` กับ DataFrame Asset | `BuildBatchRequestError` | `options must contain exactly 1 key, 'dataframe'` | `run(batch_parameters={"dataframe": df})` |
| ส่ง Key ผิด เช่น `{"df": df}` | `BuildBatchRequestError` | ข้อความเดียวกับแถวบน | ใช้ Key ชื่อ `dataframe` |
| Add Suite ชื่อซ้ำ | `DataContextError` | `Cannot add ExpectationSuite with name s_ok because it already exists.` | ตั้งชื่อใหม่ หรือ `get` ของเดิมมาใช้ |
| Add Data Source ชื่อซ้ำ | `DataContextError` | `Can not write the fluent datasource dup because a datasource of that name already exists` | เหมือนแถวบน |
| พิมพ์ชื่อ Argument ผิดตอนสร้าง Expectation (`colum="id"`) | `ValidationError` (Pydantic) | `column field required` และ `colum extra fields not permitted` | แก้ตัวสะกด (Error ขึ้นตั้งแต่ตอนสร้าง ไม่ต้องรอรัน) |
| `context.suites.get("nope")` | `DataContextError` | `ExpectationSuite with name nope was not found.` | ดูชื่อที่มีด้วย `[s.name for s in context.suites.all()]` |

</Step>

## อ่านข้อความให้เป็น

ข้อความของแถวแรกบอกทางแก้ไว้ในตัวเลย (`Please call context.suites.add(...)`) ส่วนแถวที่สองกับสามได้ข้อความเดียวกัน ทั้งที่สาเหตุต่างกัน (ลืมส่งกับส่ง Key ผิด) ข้อความนี้บอกว่าต้องมี Key เดียวคือ `dataframe` ซึ่งเป็นกติกาของ DataFrame Asset ส่วน Asset ชนิดอื่น (ไฟล์, ตาราง SQL) จะใช้พารามิเตอร์ต่างกัน ซึ่งเราดูกันใน[บทที่ 6](/great-expectations/datasources-batches/#ชนิดของพารามิเตอร์-และ-dataframe)

Error ของ Pydantic จะออกมาสองบรรทัดต่อการพิมพ์ผิดหนึ่งตัว เพราะ GX เห็นสองปัญหา คือ `column` ที่ต้องมีหายไป และ `colum` ที่ไม่รู้จักเกินมา ถ้าเห็นคู่นี้ ให้มองหาตัวสะกดที่ใกล้กัน

Error ที่เกิดจากข้อมูลมีปัญหาไม่อยู่ในตารางนี้ เพราะเมื่อคอลัมน์หายหรือค่าผิดกฎ GX จะรายงานเป็น `success=False` ในผลลัพธ์ และไม่ Raise (หน้า "[Defects GX Can Catch](/great-expectations/foundations/defects/#อ่านผลให้ถูกที่)" ใน[บทที่ 0](/great-expectations/foundations/))

<Callout type="note" title="ขอบเขตของตาราง">
ข้อความของ Asset ชนิดอื่นและของ Context แบบ File อาจต่างจากนี้ ตารางนี้ทดลองเฉพาะที่ระบุไว้ในหัวตาราง
</Callout>
