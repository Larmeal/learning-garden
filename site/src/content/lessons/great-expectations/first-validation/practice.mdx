## วิธีฝึก

คุณใช้ไฟล์ `01_first_validation.py` เป็นโครง หรือจะเขียนใหม่ในไฟล์ของตัวเองก็ได้ เฉลยทุกข้อรันจริงใน `18_result_anatomy.py` ส่วนที่ 4 ด้วย GX 1.24.1 นะ ลองทำเองก่อนแล้วค่อยเปิดเฉลย

## โจทย์ 1: ทำให้ทุกข้อผ่าน

เริ่มจาก DataFrame ของบทนี้ (`age` มี Null กับ 400) แล้วแก้ที่ข้อมูลอย่างเดียวโดยไม่แตะ Suite ให้ทั้งสี่ข้อผ่าน

ผลที่ควรได้คือ `result.success` เป็น `True` และ `success_percent` เป็น `100.0`

<details>
<summary>เฉลย</summary>

```python
df = pd.DataFrame({"id": [1, 2, 3, 4], "age": [10, 20, 30, 40], "name": ["a", "b", "c", "d"]})
```

เราใส่ `age` ให้ครบและอยู่ใน 0 ถึง 120 และมีสี่แถวพอดี จึงได้ `ex1 all pass: True 100.0`

</details>

</Step>

<Step>

## โจทย์ 2: หาค่า id ที่ซ้ำ

สมมติข้อมูลเป็น `id = [1, 2, 2, 4]` ให้เขียน Expectation ที่ล้มเพราะ id ซ้ำ แล้วอ่านจาก `result` ว่ามีกี่แถวที่ซ้ำและเป็นค่าอะไร

<details>
<summary>เฉลย</summary>

```python
gxe.ExpectColumnValuesToBeUnique(column="id")
```

ผลที่ได้คือ `success=False`, `unexpected_count=2`, `partial_unexpected_list=[2, 2]` ค่า 2 ปรากฏสองครั้งเพราะ GX นับทั้งสองแถวเป็นแถวที่ผิด ไม่ได้นับแค่ "แถวที่เกิน" (นับได้ 2 ไม่ใช่ 1)

</details>

</Step>

<Step>

## โจทย์ 3: คอลัมน์ที่ควรมีแต่ไม่มี

ตารางมีคอลัมน์ `id`, `age`, `name` แต่ผู้ใช้ต้องการให้มี `email` ด้วย ให้เขียน Expectation ที่จับได้ แล้วลองหาดูว่า `result` บอกชื่อคอลัมน์ที่ขาดไว้ตรงไหน

<details>
<summary>เฉลย</summary>

```python
gxe.ExpectTableColumnsToMatchSet(column_set=["id", "age", "name", "email"], exact_match=True)
```

ผลที่ได้คือ `success=False` โดย `observed_value` เป็น `['age', 'id', 'name']` (เรียงตามตัวอักษร) และ `details` เป็น `{'mismatched': {'missing': ['email']}}` ดังนั้นชื่อที่ขาดอยู่ใน `result["details"]["mismatched"]["missing"]`

</details>

</Step>

<Step>

## โจทย์ 4: ยอมให้ผิดได้หนึ่งในสี่

ข้อมูลเป็น `age = [10, 20, 30, 400]` ให้ตั้ง `ExpectColumnValuesToBeBetween(0, 120)` ให้ผ่านทั้งที่ยังมี 400 อยู่ในข้อมูล

<details>
<summary>เฉลย</summary>

```python
gxe.ExpectColumnValuesToBeBetween(column="age", min_value=0, max_value=120, mostly=0.75)
```

ผลที่ได้คือ `success=True`, `unexpected_percent=25.0` เพราะผิดหนึ่งจากสี่ ทำให้แถวที่ถูกเป็น 3 ใน 4 คือ 0.75 ซึ่งเท่ากับ `mostly` พอดีจึงผ่าน (เงื่อนไขคือไม่ต่ำกว่า) ถ้าลองตั้ง `mostly=0.8` จะได้ `success=False` (รันแล้วใน `18` เช่นกัน)


</details>

</Step>
