## domain คืออะไร

metric หนึ่งตัวคำนวณ "บนอะไร" ส่วนนั้นเรียกว่า domain ได้แก่ตาราง คอลัมน์ และเงื่อนไขกรองแถว (`row_condition`) metric ที่มี domain เหมือนกันทุกอย่างถูกรวมเป็นคำสั่ง SQL คำสั่งเดียว (บทหลักหัวข้อ "สองแบบ") สคริปต์ `26_registry_domains.py` ส่วนที่ 2 ถึง 3 ดูว่าเมื่อ domain ต่างกันแล้ว SQL เปลี่ยนอย่างไร (GX 1.24.1, SQLite, ตาราง `users` 4 แถว)

</Step>

## ผลต่อการออกแบบ suite

1. กฎที่ตั้งใจแยกตามกลุ่ม (เช่นเฉพาะแผน pro) จ่ายเพิ่มเป็นคำสั่งต่อกลุ่ม ถ้ามี 10 กลุ่ม ก็คือ 10 ชุด ข้อมูลใหญ่บน SQL ควรนับจำนวนกลุ่มก่อนใช้
2. `row_condition` ที่เขียนแล้วผ่านบน pandas อาจล้มบน SQL ต้องทดสอบบน engine จริง
3. ตรวจ SQL ที่ GX ส่งได้เสมอด้วยวิธีใน `05_sql_bundling.py` และ `26` (ครอบ `SqlAlchemyExecutionEngine.execute_query` เก็บคำสั่ง)

<Callout type="note" title="ขอบเขต">
ตัวเลข 2 และ 4 เป็นผลของ suite ที่ใช้ใน `26` (result_format `BOOLEAN_ONLY`) บนตารางเล็ก จำนวนคำสั่งของ suite อื่นต่างออกไปได้ และไม่ได้ทดลองกับ Spark
</Callout>
