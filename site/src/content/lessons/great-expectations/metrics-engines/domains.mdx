## Domain คืออะไร

Metric หนึ่งตัวต้องคำนวณ "บนอะไร" ส่วนนั้นเรียกว่า Domain ซึ่งได้แก่ตาราง คอลัมน์ และเงื่อนไขกรองแถว (`row_condition`) Metric ที่มี Domain เหมือนกันทุกอย่างจะถูกรวมเป็นคำสั่ง SQL คำสั่งเดียว (บทหลักหัวข้อ "สองแบบ") ส่วนสคริปต์ `26_registry_domains.py` ส่วนที่ 2 ถึง 3 จะพาดูว่าเมื่อ Domain ต่างกันแล้ว SQL เปลี่ยนไปอย่างไร (GX 1.24.1, SQLite, ตาราง `users` 4 แถว)

</Step>

## ผลต่อการออกแบบ Suite

1. ถ้าเราตั้งใจแยกกฎตามกลุ่ม (เช่นเฉพาะแผน Pro) เราต้องจ่ายเพิ่มเป็นคำสั่งต่อกลุ่ม ถ้ามี 10 กลุ่ม ก็คือ 10 ชุด ดังนั้นข้อมูลใหญ่บน SQL ควรนับจำนวนกลุ่มก่อนใช้
2. `row_condition` ที่เขียนแล้วผ่านบน Pandas อาจล้มบน SQL ได้ เพราะฉะนั้นต้องทดสอบบน Engine จริง
3. เราตรวจ SQL ที่ GX ส่งไปได้เสมอ ด้วยวิธีใน `05_sql_bundling.py` และ `26` (ครอบ `SqlAlchemyExecutionEngine.execute_query` เพื่อเก็บคำสั่ง)

<Callout type="note" title="ขอบเขต">
ตัวเลข 2 และ 4 เป็นผลของ Suite ที่ใช้ใน `26` (result_format `BOOLEAN_ONLY`) บนตารางเล็ก Suite อื่นอาจได้จำนวนคำสั่งต่างออกไป และเรายังไม่ได้ทดลองกับ Spark
</Callout>
