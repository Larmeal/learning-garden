## สองทางอ่านผล

`CheckpointResult` อ่านได้สองทางที่ให้ข้อมูลคนละระดับ

| ทาง | คืนอะไร | ใช้เมื่อ |
|---|---|---|
| `result.describe()` | JSON สรุป (สตริง) ของทั้ง checkpoint | ส่งออกเป็นข้อความ log หรือ API |
| `result.run_results` | dict: `ValidationResultIdentifier` ไปยัง `ExpectationSuiteValidationResult` | เขียนโค้ดวนดูผลเอง เข้าถึงทุกฟิลด์ของผล |

ผลจากสคริปต์ `25_checkpoint_shapes.py` ส่วนที่ 2 และ 7 (GX 1.24.1) `describe()` มี key ระดับบน 3 ตัว คือ `success`, `statistics` และ `validation_results`

</Step>

describe() เป็นสรุปที่ตัดข้อมูลบางอย่างออก (เช่น `meta`, `exception_info` ของแต่ละข้อ) เหมาะกับการดูภาพรวม ถ้าต้องการ `exception_info` ต้องเข้าทาง `run_results`

ส่วนว่า describe() ตัด `exception_info` ออกจริงหรือไม่ ตรวจจาก key ที่พิมพ์ได้: `expectations[0]` มี 4 key คือ `expectation_type`, `success`, `kwargs`, `result` ไม่มี `exception_info`

## ดึงรายการที่ล้มออกมา

วนผ่าน `run_results` ตรงๆ

```python
def failed_expectations(res):
    out = []
    for key, vres in res.run_results.items():
        for r in vres.results:
            if not r.success:
                out.append((
                    key.expectation_suite_identifier.name,
                    r.expectation_config.type,
                    r.expectation_config.kwargs.get("column"),
                    r.result.get("unexpected_count"),
                ))
    return out
```

ผลบน checkpoint ข้างบน

```text
('suite_age', 'expect_column_values_to_not_be_null', 'age', 1)
('suite_age', 'expect_column_values_to_be_between', 'age', 1)
```

ข้อ `suite_ids` ผ่านจึงไม่ถูกลิสต์ ฟังก์ชันนี้ไม่แยกว่าล้มเพราะข้อมูลหรือเพราะ exception ถ้าต้องแยก ใช้ลำดับคำถามจาก[บทที่ 4 หน้า "อ่านผลที่ไม่ผ่านอย่างเป็นระบบ"](/great-expectations/reading-results/triage/#ลำดับคำถาม)

<Callout type="note" title="ตั้งชื่อ run ได้">
`cp.run(..., run_id=RunIdentifier(run_name="nightly-2024-02-01"))` ตั้งชื่อรอบรัน และทดลองแล้วว่าชื่อนี้ไปอยู่ใน `run_results` ทุกรายการ (`RunIdentifier` import จาก `great_expectations.core.run_identifier`) `Checkpoint.run` รับพารามิเตอร์สามตัวเท่านั้น: `batch_parameters`, `expectation_parameters`, `run_id`
</Callout>
