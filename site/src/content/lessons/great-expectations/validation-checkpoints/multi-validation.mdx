## สองตัว หนึ่ง Checkpoint

สคริปต์ `25_checkpoint_shapes.py` สร้าง Validation Definition สองตัว แล้วใส่ไว้ใน Checkpoint เดียวกัน (GX 1.24.1, Pandas)

| Validation Definition | Suite | ข้อมูลที่ตรวจ |
|---|---|---|
| `vd_ids` | `id` ต้องไม่ซ้ำ | DataFrame `id=[1,2,3]` |
| `vd_age` | `age` ไม่เป็น Null และอยู่ใน 0 ถึง 120 | `age=[10, None, 400]` |

```python
cp = context.checkpoints.add(gx.Checkpoint(name="cp", validation_definitions=[vd_ids, vd_age]))
result = cp.run(batch_parameters={"dataframe": frame})
```

เมื่อรันแล้วจะพิมพ์ผลออกมาแบบนี้

```text
type: CheckpointResult | success: False
run_results entries: 2
  suite=suite_ids  success=True   evaluated=1
  suite=suite_age  success=False  evaluated=2
distinct run ids across validations: 1
results stored by this run: 2
```

- `success` ของ Checkpoint เป็น `False` เพราะตัวที่สองไม่ผ่าน เนื่องจากผลรวมคิดว่า "ต้องผ่านทุกตัวจึงจะผ่าน"
- `run_results` มีหนึ่งรายการต่อหนึ่ง Validation Definition
- ทั้งสองตัวได้ `run_id` เดียวกัน (Distinct = 1) ซึ่งบอกว่าอยู่ในรอบรันเดียวกัน
- ผลถูกเก็บลง Store สองรายการ คือหนึ่งรายการต่อหนึ่ง Validation

## พารามิเตอร์ชุดเดียวไปถึงทุกตัว

`batch_parameters` ที่ส่งให้ `cp.run(...)` จะถูกส่งต่อให้ทุก Validation Definition ดังนั้นถ้า Validation หนึ่งใช้ DataFrame Asset (ต้องการ Key `dataframe`) แล้วอีกตัวใช้ตาราง SQL ทั้งตาราง (ไม่ต้องมี Key) ชุดพารามิเตอร์เดียวก็เข้ากับทั้งคู่ไม่ได้ ซึ่งส่วนที่ 4 ของสคริปต์ได้ทดลองไว้

```text
raised: InvalidBatchRequestError | batch parameters should only contain keys from the following set: set()
        but your specified keys contain {'dataframe'} which is not valid.
```

ข้อความนี้บอกว่า Batch ของ SQL รับ Key ได้ศูนย์ตัว แต่กลับได้ `dataframe` มา ผลคือ `cp.run(...)` Raise ทั้งก้อน และไม่ได้คืนผลของตัวที่ผ่านไปแล้วมาให้ ส่วนว่าตัวแรกของคู่ถูกรันก่อนหรือไม่ เรายังไม่ได้ตรวจ

แนวทางที่ปลอดภัยคือจัดกลุ่ม Validation Definition ใน Checkpoint ตามชนิดของ Batch Definition (ที่ใช้ Key ชุดเดียวกัน) แล้วสร้าง Checkpoint แยกไว้ต่อหนึ่งกลุ่ม

<Callout type="warn" title="ที่ไม่ได้ทดลอง">
เรายังไม่ได้ทดลองกรณีที่ Validation สองตัวใช้ Key ชุดเดียวกันแต่ความหมายต่างกัน (เช่น ตัวหนึ่งไฟล์รายวัน อีกตัวไฟล์รายเดือน) และไม่ได้ทดลองการรันขนานกันของ Validation ในหนึ่ง Checkpoint
