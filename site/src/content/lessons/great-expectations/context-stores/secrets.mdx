## ปัญหา: ค่าลับไม่ควรอยู่ใน Git

Connection String ของฐานข้อมูลมักมีรหัสผ่านอยู่ด้วย ถ้าเขียนลงใน `great_expectations.yml` ซึ่ง Commit เข้า Git รหัสผ่านก็จะรั่วไปกับ Repo GX จึงแก้ด้วยการให้เขียนเป็นตัวแปร `${NAME}` แล้วแทนค่าตอนใช้งาน

```python
src = context.data_sources.add_sqlite("viafile", connection_string="${MY_DB_URL}")
```

สคริปต์ `23_persistence_config.py` ในส่วน config_variables ทดลองกับสองแหล่งของค่า (GX 1.24.1, SQLite)

</Step>

## วิธีใช้ที่แนะนำ

1. เขียนเป็น `${NAME}` ใน Connection String ทุกตัวที่มีค่าลับ
2. บนคอมพิวเตอร์ที่ใช้พัฒนา ให้ใส่ค่าใน `uncommitted/config_variables.yml` (อยู่ใน `.gitignore` แล้ว)
3. บน Server หรือ CI ให้ตั้ง Environment Variable ซึ่งชนะไฟล์ จึงไม่ต้องมีไฟล์นั้นอยู่บน Server หรือ CI เหล่านั้น

ข้อ 3 อาศัยผลที่ทดลองแล้วว่า Environment Variable ชนะ ส่วนข้อ 1 และ 2 ก็ทดลองแล้วทั้งคู่

<Callout type="warn" title="ที่ไม่ได้ทดลอง">
เรายังไม่ได้ทดลองตัวแปรแบบซ้อน (Dict) ในไฟล์ ไม่ได้ทดลองรูป `$NAME` แบบไม่มีปีกกา และไม่ได้ตรวจว่าค่าลับรั่วลงใน Data Docs หรือผลตรวจหรือไม่ ดังนั้นควรเปิดดู `uncommitted/` ด้วยตัวเองก่อนแชร์นะ
</Callout>
