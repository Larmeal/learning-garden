## สามส่วนของเมธอด

โค้ดย่อให้เหลือโครง ตัดคอมเมนต์ log และ type hint ออก

```python
aggregates = {}

# ส่วนที่ 1: จัดกลุ่ม metric ตาม domain
for bundled in metric_fn_bundle:
    domain_id = IDDict(bundled.compute_domain_kwargs or {}).to_id()
    if domain_id not in aggregates:
        aggregates[domain_id] = {"column_aggregates": [], "metric_ids": [], "domain_kwargs": ...}
    aggregates[domain_id]["column_aggregates"].append(bundled.metric_fn)
    aggregates[domain_id]["metric_ids"].append(bundled.metric_configuration.id)

# ส่วนที่ 2: หนึ่ง agg ต่อหนึ่ง domain
for aggregate in aggregates.values():
    df = self.get_domain_records(domain_kwargs=aggregate["domain_kwargs"])
    res = df.agg(*aggregate["column_aggregates"]).collect()
    assert len(res) == 1, "all bundle-computed metrics must be single-value statistics"

    # ส่วนที่ 3: แตกผลกลับเป็น metric ละค่า
    for idx, metric_id in enumerate(aggregate["metric_ids"]):
        resolved_metrics[metric_id] = convert_to_json_serializable(data=res[0][idx])
```

## ถ้าจะวัดเอง

เพื่อแปลงข้อสรุปข้างบนเป็นผลที่วัดได้ ต้องใช้ Spark ที่ติดตั้งแล้ว (เส้นทาง Spark ในสวนนี้มีโปรเจกต์ที่ `subjects/spark/code`) แล้วทำตามนี้ ทั้งหมดนี้ยังไม่ได้ทำ

1. สร้าง Spark DataFrame เล็กๆ รัน validation ที่มี suite 6 ข้อเดียวกับ `05_sql_bundling.py` (BOOLEAN_ONLY)
2. เปิด Spark UI ก่อนและหลังรัน ดูแท็บ Jobs ว่ามี job เพิ่มกี่ตัว
3. เทียบกับจำนวน domain ที่ suite มี (ตาราง, ตารางที่มี row_condition ฯลฯ) ถ้าคำอธิบายข้างบนถูก ควรเห็น job ของ aggregate ประมาณจำนวน domain บวก job ของ metric ที่ไม่ใช่ aggregate
4. สลับ `result_format` เป็น SUMMARY แล้วเทียบอีกครั้ง

<Callout type="warn" title="ทำไมยังไม่ได้ทำ">
การรัน GX บน Spark ไม่ได้อยู่ในสิ่งที่เส้นทางนี้ตรวจ หน้านี้จึงเป็นระดับซอร์สเท่านั้น ตัวเลขหรือพฤติกรรมใดเกี่ยวกับ Spark ให้ถือว่ายังไม่ยืนยันจนกว่าจะวัดตามขั้นข้างบน
