## รายการนี้มาจากไหน

ไฟล์ของแต่ละ Expectation ใน GX มีตัวแปรระดับโมดูลชื่อ `SUPPORTED_DATA_SOURCES` ซึ่งเก็บรายชื่อ Backend ที่ทีม GX ระบุว่ารองรับ และ GX เอาตัวแปรนี้ไปสร้างข้อความเอกสารของคลาส สคริปต์ `30_sql_where_support.py` ส่วนที่ 2 จะอ่านตัวแปรนี้จากโมดูลของ Expectation ทุกตัวที่ GX 1.24.1 ส่งออกมา (ตอนแรกสคริปต์อ่านจากคลาสโดยตรงแล้วไม่พบอะไรเลย เพราะมันเป็นตัวแปรของโมดูล ไม่ใช่แอตทริบิวต์ของคลาส)

| นับอะไร | จำนวน |
|---|---|
| Expectation ที่โมดูลมีรายการนี้ | 54 |
| ระบุว่ารองรับ PostgreSQL | 53 |
| ระบุว่ารองรับ SQLite | 51 |
| ระบุว่ารองรับ Spark | 48 |
| ระบุว่ารองรับ Pandas | 46 |
| ระบุว่ารองรับ BigQuery | 47 |

</Step>

<Step>

## ค้นหาเอง

ลองเลือก Backend แล้วดูว่ามี Expectation ตัวไหนบ้างที่ไม่ได้ระบุว่ารองรับ

<SupportLookup client:visible />

บน Spark มี 6 ตัวที่ไม่ได้ระบุ ได้แก่ `ExpectColumnValuesToMatchLikePattern`, `...MatchLikePatternList`, `ExpectColumnValuesToNotMatchLikePattern`, `...NotMatchLikePatternList`, `ExpectQueryResultsToMatchComparison` และ `ExpectTableRowCountToEqualOtherTable` โดยสี่ตัวแรกใช้รูปแบบ `LIKE` ของ SQL ส่วนสองตัวสุดท้ายต้องเทียบกับตารางอื่นหรือรัน Query

</Step>

<Step>

## ใช้อย่างระวัง

1. รายการนี้เป็นข้อมูลเอกสารของ GX และไม่ได้ถูกตรวจตอนรัน ดังนั้น Expectation ที่ไม่ได้ระบุ Backend ของคุณก็ยังรันได้ ถ้ามี Metric Implementation ที่ตรงกัน และตัวที่ระบุไว้ก็ยังล้มได้ ถ้าไม่มี Metric ส่วนข้อเท็จจริงของการรองรับจะอยู่ในทะเบียน Metric ([บทที่ 8 หน้า "Metric Registry"](/great-expectations/metrics-engines/registry/#ทะเบียนมีอะไรอยู่))
2. ลองดู Pandas เป็นตัวอย่าง รายการระบุ Pandas 46 ตัว แต่ทะเบียน Metric มี Implementation ของ Pandas กว้างกว่านั้น (241 Metric) สองแหล่งนี้นับคนละอย่างกัน จึงไม่ควรเอาตัวเลขมาเทียบกัน
3. ทางที่ได้ผลจริงคือลองรัน Suite กับข้อมูลตัวอย่างบน Backend จริง แล้วอ่านผลตามลำดับคำถามใน[บทที่ 4 หน้า "Failure Triage"](/great-expectations/reading-results/triage/#ลำดับคำถาม)

<Callout type="warn" title="Spark ที่ยังไม่ได้ทดลอง">
ตัวเลข 48 ของ Spark เป็นจำนวนที่เอกสารระบุเท่านั้น ไม่ได้แปลว่ารันผ่านบน Spark เพราะเส้นทางนี้ไม่ได้รัน GX บน Spark
</Callout>
