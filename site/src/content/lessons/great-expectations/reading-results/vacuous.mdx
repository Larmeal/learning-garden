## ทำไมถึงผ่านได้

expectation แบบ column map ตัดสินจากแถวที่ผิด ถ้าไม่มีแถวให้พิจารณา ก็ไม่มีแถวที่ผิด จึงผ่านตามนิยาม (ในศัพท์ตรรกะเรียกว่า vacuously true) บทหลักแสดงตารางผลสามกฎ หน้านี้ขยายเป็นแปดกฎกับข้อมูลสองแบบ ทดลองใน `21_formats_empty.py` ส่วนที่ 4 (GX 1.24.1, pandas)

- ตารางว่าง: คอลัมน์ `v` ชนิด float มี 0 แถว
- ว่างทั้งคอลัมน์: คอลัมน์ `v` มี null 3 แถว

</Step>

## กฎที่ควรเขียนคู่กัน

| ต้องการกันเรื่อง | กฎที่ใช้ |
|---|---|
| ไฟล์หรือตารางมาว่าง | `ExpectTableRowCountToBeBetween(min_value=1)` |
| คอลัมน์ว่างทั้งคอลัมน์ | `ExpectColumnValuesToNotBeNull(column=..., mostly=...)` คู่กับกฎช่วงค่า |
| ค่าเฉลี่ยหรือค่าสูงสุดคำนวณไม่ได้ | ดู `observed_value` ในผลของข้อที่ล้ม |

`mostly` ของ `NotBeNull` ใช้ตั้งสัดส่วน null ที่ยอมรับได้ เช่น `mostly=0.95` ยอมให้ null ได้ไม่เกิน 5% ของแถว (สูตรเดียวกับ `mostly` ของกฎอื่น ในที่นี้ไม่ได้ทดลองค่า 0.95 โดยตรง)

<Callout type="warn" title="ผ่านทั้งหมดไม่ได้พิสูจน์ว่ามีข้อมูล">
suite ที่มีแต่กฎแบบ column map อาจผ่านทั้งชุดบนตารางว่าง ตัวเลข `result.statistics["evaluated_expectations"]` นับจำนวน expectation ที่ถูกประเมิน ไม่ใช่จำนวนแถว จึงมากกว่า 0 ได้แม้ตารางว่าง ตัวที่จับกรณีนี้ได้คือกฎจำนวนแถว
</Callout>
