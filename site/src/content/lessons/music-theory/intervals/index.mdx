## ช่วงเสียงคือหน่วยพื้นฐานของทฤษฎีดนตรี

**ช่วงเสียง (interval)** คือระยะห่างระหว่างโน้ตสองตัว สเกล คอร์ด และเมโลดี้ล้วนอธิบายด้วยช่วงเสียง ถ้ารู้ช่วงเสียงจริงๆ ส่วนที่เหลือของทฤษฎีดนตรีเป็นแค่การประกอบ

ช่วงเสียงมีสองส่วนในชื่อ

1. **เลขขั้น (number)**: นับโน้ตตามตัวอักษร รวมตัวต้นและตัวปลาย C ถึง E คือขั้นที่ 3 (C D E) C ถึง G คือขั้นที่ 5 ไม่สนใจชาร์ปหรือแฟลต
2. **ชนิด (quality)**: บอกว่ากว้างหรือแคบแค่ไหนในขั้นนั้น ได้แก่ perfect, major, minor, augmented, diminished

ชนิดเกิดจากจำนวนครึ่งเสียงจริง ขั้นเดียวกันที่ต่างกันหนึ่งครึ่งเสียงคือเมเจอร์ (กว้างกว่า) กับไมเนอร์ (แคบกว่า) เช่น C ถึง E (ขั้นที่ 3) กว้าง 4 ครึ่งเสียง เรียก major 3rd ส่วน C ถึง E♭ กว้าง 3 ครึ่งเสียง เรียก minor 3rd

</Step>

## ตารางสิบสองช่วงเสียง

| ครึ่งเสียง | ชื่อย่อ | ชื่อเต็ม | ตัวอย่างจาก C |
|---|---|---|---|
| 0 | P1 | perfect unison | C → C |
| 1 | m2 | minor 2nd | C → D♭ |
| 2 | M2 | major 2nd | C → D |
| 3 | m3 | minor 3rd | C → E♭ |
| 4 | M3 | major 3rd | C → E |
| 5 | P4 | perfect 4th | C → F |
| 6 | TT | tritone (aug 4th / dim 5th) | C → F♯ หรือ G♭ |
| 7 | P5 | perfect 5th | C → G |
| 8 | m6 | minor 6th | C → A♭ |
| 9 | M6 | major 6th | C → A |
| 10 | m7 | minor 7th | C → B♭ |
| 11 | M7 | major 7th | C → B |
| 12 | P8 | perfect octave | C → C |

ขั้น 1, 4, 5, 8 เรียกว่า **perfect** เพราะเสียงนิ่งและไม่มีรูปแบบ major/minor ส่วนขั้น 2, 3, 6, 7 มีทั้ง major และ minor tritone (ขั้น 4 ขยายหรือขั้น 5 ลด) อยู่กึ่งกลางอ็อกเทฟพอดี (6 ครึ่งเสียง) และให้เสียงไม่นิ่งที่สุด

**ชื่อต้องสะกดถูก**: C → F♯ เป็น augmented 4th ส่วน C → G♭ เป็น diminished 5th สองคู่นี้ได้ยินเหมือนกัน แต่เขียนต่างกันเพราะเหตุผลของตัวอักษร (ขั้น 4 คือ F ขั้น 5 คือ G)

</Step>

## ลองฟังและดูบนคีย์บอร์ด

เลือกโน้ตล่างและช่วงเสียง กดฟังทีละตัวหรือพร้อมกัน สังเกตว่าชื่อโน้ตบนสะกดตามตัวอักษรเสมอ (เช่นจาก F♯ ขึ้น major 7th ได้ E♯ ไม่ใช่ F)

<IntervalLab client:visible />

**วิธีจำด้วยหู** ใช้เพลงที่ร้องได้เป็นตัวยึด (anchor) แต่ละคนเลือกตัวยึดของตัวเองจะได้ผลดีที่สุด เพลงในแล็บด้านบนเป็นตัวอย่างที่นิยมใช้กัน ถ้าไม่คุ้น ให้หาเพลงของตัวเองที่เมโลดี้ขึ้นเป็นช่วงเสียงนั้นในสองโน้ตแรก

</Step>

<Step>

## กลับช่วงเสียง (inversion)

ถ้าย้ายโน้ตตัวล่างขึ้นไปหนึ่งอ็อกเทฟ ช่วงเสียงจะ **กลับ** กฎมีสองข้อ

1. เลขขั้นรวมกันได้ 9 (3rd กลับเป็น 6th, 2nd กลับเป็น 7th, 4th กลับเป็น 5th)
2. ชนิดสลับกัน: major ↔ minor, perfect ↔ perfect, augmented ↔ diminished

ตัวอย่าง: C ถึง E (major 3rd) กลับเป็น E ถึง C (minor 6th) ผลรวมครึ่งเสียงคือ 12 เสมอ (4 + 8) ใช้ตรวจได้ทันที: ถ้ารู้ M3 = 4 ก็รู้ m6 = 8

**ประโยชน์**: จำแค่ครึ่งตาราง (ถึง tritone) แล้วอีกครึ่งคือการกลับ

</Step>

<Step>

## ช่วงเสียงบนกีต้าร์

กีต้าร์เป็นเครื่องดนตรีที่เห็นช่วงเสียงเป็นรูปทรง ทุกครั้งที่เล่นรูปเดิมที่ตำแหน่งอื่น คือช่วงเสียงเดิม

| ช่วงเสียง | รูปบนคอ |
|---|---|
| ครึ่งเสียง (m2) | เฟร็ตติดกันบนสายเดียว |
| หนึ่งเสียง (M2) | เว้นหนึ่งเฟร็ตบนสายเดียว |
| P4 | เฟร็ตเดียวกันบนสายติดกัน (ยกเว้นสาย 3 กับสาย 2 ซึ่งเป็น M3) |
| M3 | เฟร็ตเดียวกันระหว่างสาย 3 กับสาย 2 |
| P5 | สายติดกัน สายที่สูงกว่าอยู่เฟร็ตมากกว่าสองเฟร็ต (เช่น สาย 6 เฟร็ต 3 กับสาย 5 เฟร็ต 5) |
| P8 | ข้ามสองสาย เลื่อนสองเฟร็ต (หรือสามเฟร็ตถ้าคร่อม G–B) ตามบท "แผนที่คอกีต้าร์" |

ผลที่ตามมาคือพาวเวอร์คอร์ดทั้งหมด (root กับ P5) เป็นรูปเดียวที่ย้ายได้ทั้งคอ และไตรแอดทุกชนิดมีรูปที่ย้ายได้ เพราะเมเจอร์และไมเนอร์ต่างกันที่ตัวที่ 3 (M3 กับ m3) ซึ่งเป็นหนึ่งเฟร็ต

</Step>

<Step>

## ฝึกก่อนบทถัดไป

1. ท่อง M2 m3 M3 P4 P5 พร้อมจำนวนครึ่งเสียง (2 3 4 5 7) เร็วๆ
2. เลือกโน้ตหนึ่งตัว หาโน้ต P5 และ P4 ของมัน (P5 ของ A คือ E P4 ของ A คือ D)
3. เล่นเฟร็ต 5 แล้วเฟร็ต 8 บนสายเดียว (m3) สลับกับเฟร็ต 5 แล้วเฟร็ต 9 (M3) ฟังเทียบความมืดกับความสว่าง
4. ฟังเพลงที่ชอบ หาสองโน้ตแรกของเมโลดี้ แล้วลองเรียกชื่อช่วงเสียง

</Step>
