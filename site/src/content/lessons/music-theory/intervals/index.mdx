## ช่วงเสียงคือหน่วยพื้นฐานของทฤษฎีดนตรี

**ช่วงเสียง (Interval)** คือระยะห่างระหว่างโน้ตสองตัว สเกล คอร์ด และเมโลดี้ล้วนอธิบายได้ด้วยช่วงเสียง ดังนั้นถ้าเรารู้จักช่วงเสียงจริง ๆ ส่วนที่เหลือของทฤษฎีดนตรีก็เป็นแค่การเอามาประกอบกัน

ชื่อของช่วงเสียงประกอบด้วยสองส่วน

1. **เลขขั้น (Number)** นับโน้ตตามตัวอักษร รวมตัวต้นและตัวปลาย เช่น C ถึง E คือขั้นที่ 3 (C D E) และ C ถึง G คือขั้นที่ 5 โดยไม่ต้องสนใจชาร์ปหรือแฟลต
2. **ชนิด (Quality)** บอกว่าในขั้นนั้นกว้างหรือแคบแค่ไหน ได้แก่ Perfect, Major, Minor, Augmented, Diminished

ชนิดของช่วงเสียงดูจากจำนวนครึ่งเสียงจริง ขั้นเดียวกันที่ต่างกันหนึ่งครึ่งเสียงคือเมเจอร์ (กว้างกว่า) กับไมเนอร์ (แคบกว่า) เช่น C ถึง E (ขั้นที่ 3) กว้าง 4 ครึ่งเสียง จึงเรียก Major 3rd ส่วน C ถึง E♭ กว้าง 3 ครึ่งเสียง จึงเรียก Minor 3rd

</Step>

## ตารางสิบสองช่วงเสียง

| ครึ่งเสียง | ชื่อย่อ | ชื่อเต็ม | ตัวอย่างจาก C |
|---|---|---|---|
| 0 | P1 | perfect unison | C → C |
| 1 | m2 | minor 2nd | C → D♭ |
| 2 | M2 | major 2nd | C → D |
| 3 | m3 | minor 3rd | C → E♭ |
| 4 | M3 | major 3rd | C → E |
| 5 | P4 | perfect 4th | C → F |
| 6 | TT | Tritone (Aug 4th / Dim 5th) | C → F♯ หรือ G♭ |
| 7 | P5 | perfect 5th | C → G |
| 8 | m6 | minor 6th | C → A♭ |
| 9 | M6 | major 6th | C → A |
| 10 | m7 | minor 7th | C → B♭ |
| 11 | M7 | major 7th | C → B |
| 12 | P8 | perfect octave | C → C |

ขั้น 1, 4, 5, 8 เรียกว่า **Perfect** เพราะเสียงนิ่งและไม่มีรูปแบบ Major/Minor ส่วนขั้น 2, 3, 6, 7 มีทั้ง Major และ Minor ส่วน Tritone (ขั้น 4 ขยายหรือขั้น 5 ลด) อยู่กึ่งกลางอ็อกเทฟพอดี (6 ครึ่งเสียง) และให้เสียงที่ไม่นิ่งที่สุด

ชื่อของช่วงเสียงต้องสะกดให้ถูกด้วยนะ เพราะ C → F♯ เป็น Augmented 4th ส่วน C → G♭ เป็น Diminished 5th สองคู่นี้ได้ยินเหมือนกัน แต่เขียนต่างกันเพราะเหตุผลของตัวอักษร (ขั้น 4 คือ F ขั้น 5 คือ G)

</Step>

## ลองฟังและดูบนคีย์บอร์ด

ให้เลือกโน้ตล่างและช่วงเสียง แล้วกดฟังทีละตัวหรือพร้อมกัน ลองสังเกตว่าชื่อโน้ตบนจะสะกดตามตัวอักษรเสมอ (เช่นจาก F♯ ขึ้น Major 7th ได้ E♯ ไม่ใช่ F)

<IntervalLab client:visible />

วิธีจำด้วยหูคือใช้เพลงที่เราร้องได้เป็นตัวยึด (Anchor) ซึ่งแต่ละคนเลือกตัวยึดของตัวเองจะได้ผลดีที่สุด เพลงในแล็บด้านบนเป็นตัวอย่างที่นิยมใช้กัน ถ้าไม่คุ้น ก็ลองหาเพลงของตัวเองที่เมโลดี้ขึ้นเป็นช่วงเสียงนั้นในสองโน้ตแรก

</Step>

<Step>

## กลับช่วงเสียง (Inversion)

ถ้าเราย้ายโน้ตตัวล่างขึ้นไปหนึ่งอ็อกเทฟ ช่วงเสียงจะ **กลับ** โดยมีกฎสองข้อ

1. เลขขั้นรวมกันได้ 9 (3rd กลับเป็น 6th, 2nd กลับเป็น 7th, 4th กลับเป็น 5th)
2. ชนิดจะสลับกัน คือ Major ↔ Minor, Perfect ↔ Perfect, Augmented ↔ Diminished

ยกตัวอย่างเช่น C ถึง E (Major 3rd) กลับเป็น E ถึง C (Minor 6th) ซึ่งผลรวมครึ่งเสียงเป็น 12 เสมอ (4 + 8) จึงใช้ตรวจได้ทันที ถ้ารู้ว่า M3 = 4 ก็รู้ว่า m6 = 8

ประโยชน์ของเรื่องนี้คือเราจำแค่ครึ่งตาราง (ถึง Tritone) ก็พอ เพราะอีกครึ่งคือการกลับ

</Step>

<Step>

## ช่วงเสียงบนกีต้าร์

กีต้าร์เป็นเครื่องดนตรีที่ทำให้เราเห็นช่วงเสียงเป็นรูปทรง ทุกครั้งที่เล่นรูปเดิมที่ตำแหน่งอื่น ก็คือช่วงเสียงเดิม

| ช่วงเสียง | รูปบนคอ |
|---|---|
| ครึ่งเสียง (m2) | เฟร็ตติดกันบนสายเดียว |
| หนึ่งเสียง (M2) | เว้นหนึ่งเฟร็ตบนสายเดียว |
| P4 | เฟร็ตเดียวกันบนสายติดกัน (ยกเว้นสาย 3 กับสาย 2 ซึ่งเป็น M3) |
| M3 | เฟร็ตเดียวกันระหว่างสาย 3 กับสาย 2 |
| P5 | สายติดกัน สายที่สูงกว่าอยู่เฟร็ตมากกว่าสองเฟร็ต (เช่น สาย 6 เฟร็ต 3 กับสาย 5 เฟร็ต 5) |
| P8 | ข้ามสองสาย เลื่อนสองเฟร็ต (หรือสามเฟร็ตถ้าคร่อม G–B) ตามบท "[แผนที่คอกีต้าร์](/guitar/fretboard/)" |

ดังนั้นพาวเวอร์คอร์ดทั้งหมด (Root กับ P5) เป็นรูปเดียวที่ย้ายได้ทั้งคอ และไตรแอดทุกชนิดก็มีรูปที่ย้ายได้ เพราะเมเจอร์และไมเนอร์ต่างกันที่ตัวที่ 3 (M3 กับ m3) ซึ่งห่างกันหนึ่งเฟร็ต

</Step>

## ฝึกก่อน[บทถัดไป](/music-theory/major-scale-keys/)

1. ท่อง M2 m3 M3 P4 P5 พร้อมจำนวนครึ่งเสียง (2 3 4 5 7) ให้เร็ว ๆ
2. เลือกโน้ตหนึ่งตัว แล้วหาโน้ต P5 และ P4 ของมัน (P5 ของ A คือ E P4 ของ A คือ D)
3. เล่นเฟร็ต 5 แล้วเฟร็ต 8 บนสายเดียว (m3) สลับกับเฟร็ต 5 แล้วเฟร็ต 9 (M3) แล้วฟังเทียบความมืดกับความสว่าง
4. ฟังเพลงที่ชอบ แล้วหาสองโน้ตแรกของเมโลดี้ จากนั้นลองเรียกชื่อช่วงเสียงดู

</Step>
