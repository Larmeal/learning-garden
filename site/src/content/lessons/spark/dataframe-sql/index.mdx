## DataFrame คือตารางที่มี schema

DataFrame เป็นแถวและคอลัมน์ ทุกคอลัมน์มีชื่อกับชนิดข้อมูล (schema) แต่ข้อมูลกระจายอยู่ในหลาย partition บนหลาย executor คุณเขียนเหมือนใช้ตารางเดียว Spark เป็นคนแบ่งงาน

คำสั่งพื้นฐานมี SQL เทียบเท่าทุกตัว

| DataFrame API | SQL |
|---|---|
| `select("a")` | `SELECT a` |
| `filter(cond)` หรือ `where(cond)` | `WHERE cond` |
| `groupBy("c").agg(...)` | `GROUP BY c` |
| `join(other, on)` | `JOIN other ON ...` |
| `orderBy("c")` | `ORDER BY c` |

## NULL

NULL เป็นต้นเหตุของผลลัพธ์ที่ผิดคาดบ่อยที่สุดในบทนี้ กฎมีสามข้อ

- ฟังก์ชันรวมค่าอย่าง `sum` ข้าม NULL ไป
- `count(col)` นับเฉพาะแถวที่ `col` ไม่เป็น NULL ส่วน `count(*)` นับทุกแถว
- เทียบ NULL กับค่าใดๆ ได้ NULL ไม่ใช่ true หรือ false ดังนั้น `filter` จะตัดแถวนั้นทิ้ง

<Callout type="warn" title="เช็ก NULL ด้วย isNull()">
`F.col("sales") == None` ไม่ได้ผล เพราะเทียบแล้วได้ NULL เสมอ และ filter ตัดทุกแถวทิ้ง ใช้ `F.col("sales").isNull()` หรือ `isNotNull()` แทน
</Callout>

</Step>

## ลองในเครื่อง

<Callout type="try" title="รันข้อมูลชุดเดียวกับในภาพ">

```python
from pyspark.sql import functions as F
from spark_session import get_spark

spark = get_spark("sales")
rows = [("th", "bkk", 120), ("th", "cnx", 80), ("jp", "tyo", 200), ("jp", "osa", None), ("sg", "sin", 90)]
df = spark.createDataFrame(rows, "country string, city string, sales int")

df.groupBy("country").agg(
    F.sum("sales").alias("total"),
    F.count("sales").alias("n_sales"),
    F.count("*").alias("n_rows"),
).orderBy("country").show()
```

ผลที่ได้บน Spark 4.2.0

```
+-------+-----+-------+------+
|country|total|n_sales|n_rows|
+-------+-----+-------+------+
|     jp|  200|      1|     2|
|     sg|   90|      1|     1|
|     th|  200|      2|     2|
+-------+-----+-------+------+
```

กลุ่ม jp มีสองแถวแต่ `n_sales` เป็น 1 เพราะแถว osa เป็น NULL
