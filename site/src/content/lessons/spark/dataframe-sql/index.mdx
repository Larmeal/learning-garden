## DataFrame คือตารางที่มี Schema

DataFrame ประกอบด้วยแถวและคอลัมน์ ซึ่งทุกคอลัมน์มีชื่อกับชนิดข้อมูล (Schema) แต่ตัวข้อมูลจะกระจายอยู่ในหลาย Partition บนหลาย Executor เราเขียนโค้ดเหมือนกำลังใช้ตารางเดียว แล้ว Spark จะเป็นคนแบ่งงานให้เอง

คำสั่งพื้นฐานแต่ละตัวมี SQL ที่เทียบเท่ากัน ดังตารางนี้

| DataFrame API | SQL |
|---|---|
| `select("a")` | `SELECT a` |
| `filter(cond)` หรือ `where(cond)` | `WHERE cond` |
| `groupBy("c").agg(...)` | `GROUP BY c` |
| `join(other, on)` | `JOIN other ON ...` |
| `orderBy("c")` | `ORDER BY c` |

## NULL

NULL เป็นต้นเหตุของผลลัพธ์ที่ผิดคาดบ่อยที่สุดในบทนี้ โดยมีกฎอยู่สามข้อ

- ฟังก์ชันรวมค่าอย่าง `sum` จะข้าม NULL ไป
- `count(col)` นับเฉพาะแถวที่ `col` ไม่เป็น NULL ส่วน `count(*)` นับทุกแถว
- เมื่อเทียบ NULL กับค่าใด ๆ จะได้ NULL ไม่ใช่ True หรือ False ดังนั้น `filter` จะตัดแถวนั้นทิ้ง

<Callout type="warn" title="เช็ก NULL ด้วย isNull()">
`F.col("sales") == None` ใช้ไม่ได้ เพราะเทียบแล้วได้ NULL เสมอ และ Filter จะตัดทุกแถวทิ้ง ให้ใช้ `F.col("sales").isNull()` หรือ `isNotNull()` แทน
</Callout>

</Step>

## ลองในเครื่อง

<Callout type="try" title="รันข้อมูลชุดเดียวกับในภาพ">

```python
from pyspark.sql import functions as F
from spark_session import get_spark

spark = get_spark("sales")
rows = [("th", "bkk", 120), ("th", "cnx", 80), ("jp", "tyo", 200), ("jp", "osa", None), ("sg", "sin", 90)]
df = spark.createDataFrame(rows, "country string, city string, sales int")

df.groupBy("country").agg(
    F.sum("sales").alias("total"),
    F.count("sales").alias("n_sales"),
    F.count("*").alias("n_rows"),
).orderBy("country").show()
```

ผลที่ได้บน Spark 4.2.0

```
+-------+-----+-------+------+
|country|total|n_sales|n_rows|
+-------+-----+-------+------+
|     jp|  200|      1|     2|
|     sg|   90|      1|     1|
|     th|  200|      2|     2|
+-------+-----+-------+------+
```

กลุ่ม jp มีสองแถวแต่ `n_sales` เป็น 1 เพราะแถว Osa มี `sales` เป็น NULL

</Callout>
