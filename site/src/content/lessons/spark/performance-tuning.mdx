> บทนี้ยังเป็นเมล็ด ยังไม่มีเนื้อหาเต็ม จะเติมเมื่อถึงคิวเรียน

## จะครอบคลุม

- data skew และวิธีแก้ (salting, AQE skew join)
- join strategy: broadcast กับ sort-merge
- cache / persist ใช้เมื่อไร
- ขนาด partition และ spark.sql.shuffle.partitions
- spill และ memory
